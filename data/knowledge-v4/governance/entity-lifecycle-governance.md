> 版本：V1.0
> 日期：2026-07-18
> 实施阶段：V4.0 Phase 5

## 一、四档状态定义

| 状态 | 含义 | 触发条件 | 恢复条件 |
|------|------|---------|---------|
| **active** | 活跃 | 默认初始状态；近期有交互 | — |
| **dormant** | 蛰伏 | 连续 90 天无交互 | 用户再次提及，自动恢复 |
| **archived** | 封存 | 持续 365 天无交互 | 仅手动操作可恢复为 active |
| **deceased** | 永久注销 | 用户主动标记 | **不可恢复** |

## 二、状态流转图

```
  ┌──────────┐   >90天无交互   ┌──────────┐   >365天无交互   ┌──────────┐
  │  active  │ ──────────────→ │ dormant  │ ───────────────→ │ archived │
  │  (活跃)  │                 │  (蛰伏)  │                   │  (封存)  │
  └──────────┘                 └──────────┘                   └──────────┘
       ↑                           │                              │
       │   近期有交互(<90天)       │   仅手动操作                │   仅手动操作
       └───────────────────────────┘                              │
                                                                  ↓
       ┌──────────┐                                           ┌──────────┐
       │  任何状态  │ ──── 用户手动标记 ────→                  │ deceased │
       └──────────┘                                           │ (永久注销)│
                                                               └──────────┘
```

## 三、触发机制

| 机制 | 触发频率 | 职责 |
|------|:--:|------|
| **实时检查** | 每次 `getPersonProfile()` 调用 | 单实体状态判断（已实现于 `_checkStatusDowngrade`） |
| **批量扫描** | 每日一次（DailyMaintenanceScheduler） | 全库扫描，批量执行状态流转（`LifecycleManager.runDaily()`） |
| **手动操作** | 用户指令触发 | 主动标记 deceased 或恢复 archived（`setEntityStatus()`） |

## 四、档案处置

| 状态 | 黑钻钙化 | PAE 采集 | 对话归档 | 检索优先级 |
|------|:--:|:--:|------|:--:|
| active | 正常 | ✅ 正常 | 正常 | 正常 |
| dormant | -1 级 | ✅ 仍可采集 | 保留 | 降低 |
| archived | 降至 1 级 | ⚠️ 暂停(除非用户明确提及) | 归档 | 最低 |
| deceased | 停止钙化 | ❌ 停止 | 永久保留 | 仅审计查询 |
