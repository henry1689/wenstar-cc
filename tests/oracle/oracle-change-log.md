# oracle 与治理对象变更登记表

**分级依据**：`oracle-change-policy.md`
- **R1** —— 工程方可改，但必须留痕（常量取值、层映射、测试用例、日志与格式化）
- **R2** —— 必须由 oracle 方出补丁或业主签字（计算路径、容差、采样、判定条件）
- **R3** —— 必须业主签字（改变 R2 语义、改容差、放宽任何断言）

**填写纪律**
- 「变更人」按包内信息只能写**执行方**，不得虚构具体人名。
- 「复核人」**不得由执行方自填**，一律写「待指定」，由统筹者/业主指派后回填。
- 哈希为**变更后**文件的 SHA-256（变更前值取上一行的「后」值）。
- 每一行都必须能被 `git show <commit> --stat` 复核；对不上的行等同未登记。
