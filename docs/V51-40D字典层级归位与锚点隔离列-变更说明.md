## 六 鲁棒性（ROBUST）

- **非表层补丁**：主路径（`write()` / `writeMemory()` 显式写 `namespace`）与异常分支（锚点继承查询 `catch → 按 default 落库` + 打警）**同时实现**，不是只修主路径。`ROBUST_NO_SURFACE_PATCH` 成立。
- **持久化保护**：`scheduleFlush` 防抖、`flushNow` 强制落盘、事务回滚保护均未删除；继承查询失败**不阻塞**锚点重建（单行 catch，与该函数其它继承位同策略）。
- **不涉及 LLM 调用链路**：无超时/重试/熔断相关改动。
- **无硬编码**：未新增人名、未新增时间常量（时间取 `now` 与既有参数）。
