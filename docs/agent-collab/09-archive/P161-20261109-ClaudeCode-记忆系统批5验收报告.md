### 3.1 指标定义（先定义再测量）

| 指标 | 定义 |
|---|---|
| 深度召回覆盖率 | 对 12 个代表主题 × 检索主体，`sweepAllStores + collectEvidenceLayer` 至少返回 1 条的比例；**同时给出「可召回主题覆盖率」**（库里确无该主题候选的查询不计入失败，避免把数据缺失算成管道失效） |
| 纯回避率 | 有记忆素材时，回复含回避词（不记得/记不清/没印象/想不起来）**且完全没有任何回忆表达**的比例；法源允许的「细节记不清了——但那会儿的感觉是记得的」**不计**回避 |
| 三重奏出现率 | 回复同时/多数具备「回味 / 叠加 / 憧憬」三层中的 ≥2 层（关键词语义判定） |
| 要素落地率 | 回复至少包含一条注入素材中的中文要素片段 |
| 跨实体越权 | 以实体 A 检索、用实体 B 的话题词，返回片段中「无任何一行属于 A（且非共享知识）」的条数 |
| 四路 round-trip | 同一条完整编码记忆经 UUID / DNA / 40D / 关键词四路都能召回 |
