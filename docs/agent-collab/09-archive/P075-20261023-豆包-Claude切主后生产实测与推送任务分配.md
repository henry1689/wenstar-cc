## 二、任务分配

### 任务 1：生产实测（P0，最高优先级）

**目标**：验证新架构（GroupSession 分支）在真实运行环境下的核心行为。

#### 实测项

**单人会晤（最常用场景）**：
1. 进入会晤：用户说"找徐诗雨聊聊"→ 进入徐诗雨会晤
2. 退出会晤：用户说"结束"→ 回到玉瑶
3. 现场恢复：退出后玉瑶的场景/情感基线/角色复原（非归零、非固定 secretary）
4. 日志验证：出现 `[GroupShadow] 玉瑶现场已恢复=true`

**多人会晤**：
5. 加人：会晤中说"叫阿珍过来"→ 参与者增加
6. 换发言：提及当前参会者 → 发言人切换（粘性保持）
7. 减人：说"阿珍先回去"→ 参与者减少
8. 会议纪要：多人会晤退出后纪要正常生成（A1 专项验证，recordTurn 四参）

**旧数据召回**：
9. 会晤徐诗雨时，旧对话组数据能正常召回
10. 退出会晤后，玉瑶的旧记忆正常召回

**回滚验证**：
11. 关 WS_GROUP_V2=0 重启 → 旧路径正常工作
12. 再开 WS_GROUP_V2=1 → 新架构恢复

#### 实测方式

- 用 API 调用：`POST http://localhost:3000/api/chat`，body `{message, tts:false}`，UTF-8 编码
- 或通过 webui 界面测试
- 每项实测记录：输入 → 输出 → 日志关键字 → 是否通过
- 发现问题立即记录，不打包，写报告
