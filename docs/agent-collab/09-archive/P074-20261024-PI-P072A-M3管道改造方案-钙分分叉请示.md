# P074 · P072-A M3 内部 24D 管道改造方案

## 二、核心矛盾（为何不能闭眼改）

**40D 的维度定义体系里根本没有「认知逻辑象限」**：
- 24D 有 factual/logical/certainty/abstract/temporal_focus 认知 6 维（EmotionScorer/CognitionScorer 打分产物）
- 40D 是「瑶灵肉身 D1-8 + 精神内核 D9-14 + 圈层人际 D15-20 + 时空环境 D21-32 + 亲密纹理 D33-40」——**认知逻辑维不存在，也无处安放**（d10/d11/d13/d16/d18/d20 已有法定定义，不能挪用）
- 因此 7 个钙分依赖的无家槽，**要么给钙分换算式，要么立法豁免**——这是分叉点
- 同时 `arousal` 与 `d03_nerve_arousal`（神经唤醒）语义高度重合——是否允许词表规则写入 d03（原白皮书称瑶灵通道产出）是**边缘合宪问题**

**触碰的既有铁律**：P071 备注「不改钙分量纲、不改晋升阈值」（保护系统命门）。钙分公式换输入必然改数值 → 存量钙分与新算不可比 → 晋升/衰减行为漂移。

## 三、三条路径（请业主裁决）

### 路径一：彻底合规（**我推荐**，符合「避免死灰复燃」意志）
1. A1 scorers 直写 `PerceptionV40`（14 有家槽全量；`arousal` 迁 `d03_nerve_arousal`【需确认】；其余 6 认知槽停止产出）
2. A2 钙分公式重构为 **40D 合法维输入**（12 safeVal → 5-6 合法维加权）；先**并行双算**：新旧两套钙分跑同一批存量对比分布，漂移可解释才切主
3. A3 情绪标签/injectContext/场景调整全部改 40D 键
4. A4 **存量钙分一次性重算 + 与三量纲统一（P072-D）合并**做（停服窗口，备份+export 纪律）
- 代价：钙分数值体系换代，晋升行为需实测回归验证；测试面大（50 文件 175 处）
- 收益：法令彻底落地，24D 归零，死灰不能复燃

### 路径二：行为保持（保守，但触法令字面）
- 7 个无家槽降级为「M3 内部认知特征」：不落库、不构成检索量纲、不参与投影——但 `Perception24D` 类型作为量纲接口仍存在于代码 → **与法令第一条字面冲突，需要业主对法令做豁免注脚**才能走
- 优点：钙分零漂移、改造量减半（只清投影链与落库点）

### 路径三：补充立法后执行
- 业主先裁决 7 无家槽的归宿（删贡献 / 豁免为内部特征 / 迁入近义维），我按裁决执行路径一或二

## 四、我建议的裁决组合（供参考）

**路径一 + 分四步（A1→A2 双算→A3→A4 停服重算）**，理由：
- 您的立法原话「只有 40D 一种才能在任何地方出现」——路径二留着 24D 类型就是「出现在任何地方」
- 钙分三量纲本来就要统一（P072-D 在册），与钙分公式 40D 化**合并为一次停服迁移**比分两次更稳
- 双算对比把「行为漂移」从风险变成可观测数据，符合「先验证再写大代码」

## 五、裁决后执行顺序（交本窗口或专项）

1. A1+A3（类型与消费方改造，50 文件 175 处，Harness 分批走，每批独立测试）
2. A2 双算对比报告（不切主，产出新旧钙分分布差异给业主看）
3. A4 停服窗口：钙分重算 + perception_v2 列退役 + 三量纲统一（三合一）
4. P072-C/V11 残余投影、P072-E 文档清扫随后
