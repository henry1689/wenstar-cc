## 二、业主裁决（最高效力）

### 裁决原则
1. 法律按最新为准：法律内部冲突时，以最新版本条款为准
2. 只增不减的准确含义：合理合规、信息完整、有用且能被读取召回的信息才只增不减；残缺、垃圾、不合理不合规的信息必须清理，清理合法
3. 法律修改程序：大家达成共识但与现有法抵触时可修改法律，一切以合理合法高效性价比优先；法律通过大家确定后修改，绝不允许 agent 独自修改法律

### 具体裁决
| # | 事项 | 裁决 |
|---|---|---|
| 1 | relationMap | 保留（第二十五条要求存主观相处规则） |
| 2 | 边删除范围 | 仅限孤儿边/重复边/未定义边 |
| 3 | 采集引擎 | PAE 扩展（法律第十四条规定 PAE 是唯一合法引擎），吸收双来源/JSON schema/三级去重设计 |
