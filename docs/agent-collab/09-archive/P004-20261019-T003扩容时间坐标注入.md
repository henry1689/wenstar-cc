## 修复（单源原则）

1. **memFragWithTime 单源格式化**：当年 `【X·10-16】` / 跨年 `【X·2025-12-31】` /
   无合法时间回退旧标签（fail-open，坏数据不阻塞注入）。每条约 +6 字符，V35-C 预算内。
2. **11 个注入点接线**：主通道（近期/历史/锚点/最早槽四路汇流）、关键词相关、统一中枢、
   砂金重要记忆（SQL 补 created_at）、金库会晤路径、金库户主 fallback（两 SQL 补列）、
   砂金更早原文、V5.3 对话降级、户主回忆、户主用户曾提到。
   遗留仅：【时间检索】（自带"昨天/上周"语义）/【对话原文】【作品】（长内容，时间价值低）/
   【反编造铁律】（指令非记忆）。
