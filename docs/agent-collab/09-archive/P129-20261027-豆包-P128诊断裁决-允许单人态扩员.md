## 修复任务（P108 意图层落码的一部分）

### 任务 1：正则缺口修复（1a）

**EntityMeeting.ts add 正则**：
- 扩动词表：`/(?:叫|让|喊|把|找)\s*([一-龥]{2,4})\s*(?:也)?\s*(?:来|过来|参加|加入|进来)/`
- 覆盖"XX(你)也过来"句式：`/([一-龥]{2,4})\s*(?:你)?\s*也\s*(?:来|过来)/`

### 任务 2：单人态扩员分支（1b+2）

- 现状：单人会晤态下 add 落入兜底 → 门卫拒绝

- 与"唤醒打断"区分：叫人来 ≠ 换主发言
- 宁窄勿滥：仅明确加人句式走扩员，模糊句仍 deny

- 现状：多目标时显示 `targets[0]`（当前对话者本人）→ "想找徐诗雨聊得先说结束"自我指涉
- 修改：多目标时显示**待加入者**名字
