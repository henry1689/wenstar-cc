# P053 · 记忆逻辑链路彻查 + 统一口径结构方案

> 目标（业主）：治徐诗韵只是切入口，**彻底理清整条逻辑链 → 结构上改善 → 适用所有人 → 根除多套口径，达成完全统一**。

## 一、完整记忆逻辑链路（现状测绘）

```
对话轮次
  ├─→ 及时上下文（RAM）= contextWindowTurns 80条≈40轮  ← 丝滑短期记忆
  ├─→ 压缩: threshold 200条 超限归档最早的 / keepFullTurns 100条 保完整
  └─→ 砂金库 memories（短期层）
         ├─ 召回窗 sandboxRecallWindowDays = 21天（上下文不足时后补·优先召回）
         ├─ 超窗/超30天: compactAlluvial(30天) → is_compacted=1 归档
         └─ 晋升 autoPromoteCandidatesV2 → 金库 vault_log（中期）
                              └→ 黑钻 black_diamond（长期·**无时间窗**）
```

## 三、徐诗韵切入口 → 全人类根因

**她的根因链**：亲密记忆钙 **0.625(0-1量纲)** → 晋升候选 `calcium>=0.9` **不满足** → **永不晋升** → 滞留砂金（>21天窗）→ **召回不到 → "记不得"**。

**这不是她独有**——任何「有意义但低钙」的记忆（亲密/情感/关系/新记忆）都撞同一堵墙：
- 晋升阈值 `calcium>=4.5(0-5) / recall>=5 / landmark / multi-factor≥5` 对低钙情感记忆**够不到**
- 且量纲混乱让"够不够得到"本身就不可靠（0.625 归一后 3.125 <4.5）

**多套口径的成因**（业主判断属实）：不同时代/修不同人时打补丁，各写各的钙分尺度（0-1/0-5/0-10）与阈值，堆积成三量纲 + 混用判据。

## 四、统一口径结构方案（根治，适用所有人）

| # | 统一项 | 方案 | 治什么 |
|---|---|---|---|
| **U1** | **钙分单一量纲** | 全库 `calcium_score` 归一到**单一量纲（建议0-5）**，迁移历史数据；所有阈值（晋升/排序/衰减/召回）基于该量纲 | 三量纲混用（总根源） |
| **U2** | **晋升判据单一量纲** | 候选/评估 SQL 全部用统一量纲（消除0.9/4.5混用），阈值集中一处 | 晋升错判 |
| **U3** | **情感/关系低钙晋升通道** | 统一量纲下，为亲密/情感/关系类记忆加独立晋升路径（低钙但高情感值也可晋升），不再只有 calcium>=4.5 一条 | 徐诗韵类低钙有意义记忆永卡砂金 |
| **U4** | **窗口真源收口** | `contextWindowTurns(80)` 唯一真源；清除 m5 `slice(-20)`、chat `slice(-10/-2)` 等残留 slice 改读真源 | 补丁堆积的零散窗口 |
| **U5** | **三层召回贯通** | 砂金(21天)+金库+黑钻(无窗) 按统一钙分跨层排序 = 人脑强度分层 | cue 跨期检索 |

## 五、建议实施顺序
1. **U1 钙分量纲归一**（数据迁移，停服窗口 + dry-run 先行）——**其他都依赖它**（晋升/排序/衰减都要统一量纲）
