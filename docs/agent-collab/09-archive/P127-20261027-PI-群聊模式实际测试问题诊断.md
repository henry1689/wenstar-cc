## 🔴 三个核心问题

### 问题 1：加人功能不工作
**现象**：用户说"找阿珍过来一起聊聊"，徐诗雨只是说"去叫阿珍"，但阿珍**没有实际加入群聊**。

**预期**：用户说加人 → 系统应该触发 `addParticipant` 意图 → GroupSession 把阿珍加入 participants → 后续对话应该是徐诗雨+阿珍两个人轮流说话。

### 问题 2：多人对话不生效
**现象**：用户说"找徐诗雨和阿珍一起聊聊"，系统提示"正和徐诗雨聊着呢"——说明系统认为已经在和徐诗雨聊了，不能直接加阿珍。

**预期**：用户说"找两个人一起聊" → 系统应该识别为多人会晤意图 → 同时加入徐诗雨+阿珍 → 两个人都应该说话。

### 问题 3：退出后状态没正确重置
**现象**：用户说"再见"退出后，再说"找徐诗雨和阿珍过来一起聊聊"，系统又提示"正和徐诗雨聊着呢"——说明退出后状态没正确重置。

**预期**：退出后 GroupSession 应该清空 → 下次说"找两个人聊"应该能正常开始新的多人会晤。
