## 二、方向修正：回到初衷——以语义块为记忆单元

P0是单条message级别的数据卫生清理，是前置工作，不是目标。**真正的目标是以对话组/语义块为基本单位的A/B双链路架构。**

### 当前对话块架构状态（实测）

- dialog_groups表：209条（从27条增长），字段完善
- 已有：block_calcium_score（块级钙化分，最高6.83）、emotion_curve（情感曲线）、scene_anchor_hash、narrative_tag、turn_count、闭组原因
- conversations关联率：90%
- memories关联率：43.4%（剩余56.6%需补挂）
- 标注完整度：memories DNA 97.7% / 40D 100% / UUID 97.1%；conversations UUID 99.8% / DNA 99.4%

### 关键差距

| 维度 | 目标 | 当前 |
|---|---|---|
| A链路钙化单位 | 以对话块为单位 | 块级钙化分已有，但检索召回仍以单条memory为单位 |
| A链路允许遗忘 | 块级权重衰减/suppressed | 209个块全部active，无lifecycle流转 |
| B链路wiki摘要 | 每块三层摘要 | **block_summary全部为null（0/209）** |
| B链路块级40D | 冻结EventState_40D | dialog_groups无40D列，只有emotion_curve |
| B链路单点读取 | 按块ID读取，禁止全局检索 | 无块级读取API |
| 两路锚点 | A召回块→B加载原文 | 检索时不通过块ID拉B链路 |

## 三、下一步建议（T002任务书待写）

### P1-A：A链路块级化
1. 检索召回从单条memory改为以dialog_group为单位——先召回块，再从块内取代表片段
2. 块级lifecycle状态机：active→decaying→suppressed→archived
3. 块级钙化公式：block_calcium = α×召回次数 + β×情感峰值 + γ×时间衰减 + δ×B链路消费次数
4. 块级"允许遗忘"：低权重块不删除，检索优先级沉底

### P1-B：B链路块级wiki化
1. 闭组时自动生成block_summary（标签/叙事/情感三层）
2. 新增块级40D冻结向量，闭组时快照，写入后只读
3. BArchiveReader按dialog_group_id单点读取
4. 禁止B链路全局检索

### P1-C：两路锚点打通
1. A链路检索结果改为"块+块内代表片段"
2. 深度回忆时通过块ID加载B链路完整原文+摘要
3. B链路消费次数回写A链路块级钙化δ因子
