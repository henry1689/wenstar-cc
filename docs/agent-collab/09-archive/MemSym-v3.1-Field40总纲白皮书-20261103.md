## 〇、v3.1 修订：先修正 v3 的四处缺陷

### 0.1 缺陷清单

| # | 缺陷 | 原因 | 后果 |
|---|---|---|---|
| 1 | 未知维度被当成完美匹配 | v3 高斯核里 σ→∞ 时，指数项趋于 0，s_L 趋于 1 | 一整层都没有数据，反而得满分，还会被计入 minLayers |
| 2 | 精度越低，得分越高 | σ_x 越大，指数项越小，s_L 越接近 1 | v3 §七 的精度衰减让越久远、越模糊的记忆越容易被触发，和设计意图正好相反 |
| 3 | 独特性 ρ 基本不起作用 | 按 6 层码的组合计数，组合数是 6^6 ≈ 6.9×10¹⁰，几乎每个组合只有 1 条印记，D(x) 区分不出任何差别；而且依赖码本，码本一重训就失效 | 独特性退化为常数 |
| 4 | 三个主体各存一份 40 维 | 场景层描述的是同一个世界，dyad 不需要身体层 | 冗余存储，还会出现"同一时刻，三份场景值互相矛盾"的情况 |

### 0.2 新打分：证据似然比（线索诊断性）

认知心理学原理：**线索诊断性**（Nairne 2002，*The myth of the encoding–retrieval match*）。一个线索能唤起某段记忆，不是因为二者相似，而是因为这个线索能把这段记忆和其他记忆区分开。

据此，每一维的打分改为"这条印记解释当前状态的能力，比'普通状态'强多少"。

**第一步：印记向背景收缩**（模糊的记忆会退回到"平常的样子"，即 Bartlett 的图式回归）：

```
x̂_i = (p_x · x_i + p_0 · μ_i) / (p_x + p_0)
v_i = 1 / (p_x + p_0)
p_x = σ_x,i⁻² ,  p_0 = τ_i⁻²
```

其中 μ_i、τ_i 是该用户在这一维上的长期均值和标准差，即背景分布。

**第二步：每维的对数似然比：**

```
ℓ_i = ½ ln(b_i²/s_i²) + (q_i − μ_i)²/(2 b_i²) − (q_i − x̂_i)²/(2 s_i²)
s_i² = σ_q,i² + v_i ,  b_i² = σ_q,i² + τ_i²
```

ℓ_i 截断在 [−3, 3]，避免单一维度一票否决或一票通过。

**第三步：层证据与总分：**

```
E_L = Σ_{i∈L} w_i · ℓ_i
E   = Σ_L m_L · E_L
R   = σ(a·(E − E_0)) · D(x) · G(x)
```

**性质验证：**

| 情形 | 结果 | 含义 |
|---|---|---|
| 印记某维未知（p_x = 0） | x̂ = μ, v = τ² ⇒ ℓ = 0 | 未知就是"没有证据"，不再是完美匹配 ✅ |
| 印记已经很模糊 | x̂ 收缩到均值，ℓ → 0 | 模糊的记忆更难被唤起 ✅ 修复缺陷 2 |
| 在少见的值上吻合（q = x = μ+2τ） | 约 +2.5 | 特别的时刻证据更强 |
| 在常见的值上吻合（q = x = μ） | 约 +0.8 | 常见场景证据弱，自然抑制线索过载 |
| 精确地不吻合 | 负值，截断到 −3 | 反证也计入 |
| 总分是各维之和 | 贡献可以精确分解 | 可解释输出天然忠实（见 §3.6） |

上表数值以 σ_q = σ_x = 0.1, τ = 0.3 计算。

```typescript
/** 单维证据：印记 (x, sx2) 相对背景 (mu, tau2) 解释查询 (q, sq2) 的对数似然比 */
export function dimEvidence(q: number, sq2: number, x: number, sx2: number, mu: number, tau2: number): number {
  if (!isFinite(sq2) || sq2 >= tau2) return 0;              // 查询这一维不可靠 → 无证据
  const px = isFinite(sx2) && sx2 > 0 ? 1 / sx2 : 0;
  const p0 = 1 / tau2;
  const xh = (px * x + p0 * mu) / (px + p0);
  const v = 1 / (px + p0);
  const s2 = sq2 + v, b2 = sq2 + tau2;
  const l = 0.5 * Math.log(b2 / s2) + (q - mu) ** 2 / (2 * b2) - (q - xh) ** 2 / (2 * s2);
  return Math.max(-3, Math.min(3, l));
}
```

**层内相关性**：同一层里高度相关的维度会重复计入证据。P0 的 PCA 完成后，层内先做白化（用该层协方差的 Cholesky 分解去相关），再逐维计算；在此之前，用 w_i = 1/(1 + Σ_{j≠i}|r_ij|) 做近似折扣。

## 一、Schema、信度与精度体系

### 1.1 ICC 信度测试怎么做

结论：只对同一段文本反复调用 LLM，测到的是自洽性，不是信度。模型可能每次都稳定地给出同一个错误答案。需要做三项研究，取其中最弱的一项作为判定依据。

| 研究 | 评估者 | 样本 | ICC 类型 | 回答的问题 |
|---|---|---|---|---|
| S1 自洽 | 同一模型，5 次采样（T=0.7）× 2 种提示词 | 300 个 episode | ICC(2,1) 绝对一致 | 模型的估计稳不稳 |
| S2 人际上限 | 2–3 名人工标注员 | 120 个 episode 金标集 | ICC(2,1) | 人自己能不能标准。人都标不准的维度，模型也不可能标准 |
| S3 效度 | LLM 共识值 vs 人工共识值 | 同 S2 | ICC(2,1) + Bland–Altman | 模型估得对不对 |

判定标准参考 Koo & Li（2016）：低于 0.5 差，0.5–0.75 中等，0.75–0.9 良好，高于 0.9 优秀。判定值取 min(S2, S3)。

采样三个关键点：

1. **分层采样**：ICC 依赖目标之间的方差。样本里 D23 愠怒几乎都是 0 时，即使评估者完全一致 ICC 也会很低。先用规则预筛，让每一维的高、中、低值都有足够样本，低发维度（D20、D21、D23）过采样；
2. **样本量**：约 100 个目标、3 名评估者，可把 ICC≈0.7 附近的 95% 置信区间宽度控制在 ±0.1 左右（Bonett 2002 方法）。金标集 120 个足够；
3. **补充指标**：同时报告 Krippendorff α（区间尺度）和平均绝对差，防止被 ICC 单一指标误导。

### 1.2 在线规则估计与睡眠 LLM 精估的偏差和精度校准

方法：以金标（有人工标注时）或 S1 的 5 次采样均值（伪金标）为参照，对每个 (来源, 维度) 组合：

1. **偏差**：画 Bland–Altman 图，看平均差（系统偏差）和一致性界限；
2. **校准映射**：拟合保序回归或线性映射 v' = f_src,i(v)，在线读数先校准再使用；
3. **精度**：校准后的残差方差决定精度，π_src,i = 1 / Var(gold − v')；
4. **只在有信号时给精度**：规则词表没有命中时，输出精度 0，而不是值 0。命中和未命中分开统计残差。

### 1.3 弱信度维度的降级策略

由 ICC = τ²/(τ² + σ_err²) 可得精度上限：

```
π_cap,i = ICC_i / ((1 − ICC_i) · τ_i²)
```

ICC = 0.5 时，测量误差正好等于人群离散度，读数在收缩公式里只占一半权重，弱维度自动降权。在此基础上再叠加显式规则：

| ICC 等级 | 共振打分 | 其他用途 |
|---|---|---|
| ≥ 0.75 | A：全权重 | 全部可用 |
| 0.5–0.75 | B：w_i ≤ w_i_base · (ICC − 0.5)/0.25 | 可用于表达 |
| < 0.5 | C：w = 0，不参与打分 | 只用于观测和表达的语气 |
| 连续两轮 < 0.5 | — | 合并或删除，进入下一版 schema |

预判的弱维度和备选处理：

| 维度 | 为什么难 | 备选 |
|---|---|---|
| D13 确定性 | 从文本很难区分"不确定"和"谨慎措辞" | 与 D12 应对能力合并为"可控感" |
| D15 价值相容 | 依赖对价值观的深度理解 | 降级为 C 级，只影响表达 |
| D26 被理解感 | 用户的内心感受，文本里很少直接说 | 改为 dyad Y5 回应性：回复是否理解、认可、关心了对方，这些是可观测的行为，信度高得多 |
| D14 归因 | 中文常省略主语 | 由睡眠期 LLM 结合上下文估计，在线不估 |

### 1.4 多源贝叶斯融合：冲突惩罚与同源修正

纯加权平均有两个问题：同源读数被重复计入（TEXT_LLM 和 TEXT_RULE 都来自同一段文字，不是独立证据），以及冲突被平均掉。

**① 同模态内部先合并**（近似协方差交叉）：

```
π_g = max_s π_s + η · (Σ_{s∈g} π_s − max_s π_s) ,  η = 0.3
```

**② 跨模态融合**：

```
v̄ = Σ_g π_g v_g / Σ_g π_g ,  π = Σ_g π_g
```

**③ 冲突检验与精度膨胀（Birge 比率）**：

```
Q = Σ_g π_g (v_g − v̄)²
π ← π / max(1, Q/(G−1))
```

一致时 Q 约等于自由度 G−1，不惩罚；冲突越大，精度降得越多。

```typescript
export function fuseDim(readings: DimReading[], cap: number): FusedDim {
  const byMod = groupBy(readings.filter(r => r.pi > 0), r => modalityOf(r.src));
  const groups = [...byMod.values()].map(rs => {
    const pis = rs.map(r => r.pi), maxPi = Math.max(...pis);
    const v = rs.reduce((s, r) => s + r.pi * r.v, 0) / sum(pis);
    return { v, pi: maxPi + 0.3 * (sum(pis) - maxPi) };
  });
  if (!groups.length) return { v: 0, pi: 0, conflict: 0 };
  const P = sum(groups.map(g => g.pi));
  const v = groups.reduce((s, g) => s + g.pi * g.v, 0) / P;
  const G = groups.length;
  const Q = groups.reduce((s, g) => s + g.pi * (g.v - v) ** 2, 0);
  const inflate = G > 1 ? Math.max(1, Q / (G - 1)) : 1;
  return { v, pi: Math.min(P / inflate, cap), conflict: inflate > 3 ? Q : 0 };
}
```

举例：心率高 + 文本强愉悦**不构成冲突**——生理信号对效价的精度约为 0，它只为唤醒度提供证据，"高唤醒 + 正效价"就是兴奋，二者一致。

真正的冲突出现在同一维上：比如文本说"我很平静"，但语音紧绷、心率高，这是唤醒度 D08 上的冲突。处理方式：

- 精度膨胀，说明系统此刻不确定；
- 记录一个 `expression_mismatch` 标志，即"嘴上说没事"。它只能用于更温和的关心方式，**绝不能当面拆穿，也绝不能记成"用户撒谎"**。这一条写进 Harris。

### 1.5 不同来源的精度怎么统一刻度

原则：所有精度都相对同一把尺子标定，即 §1.2 的金标，单位是"该维度值域上方差的倒数"。PHYSIO 和 TEXT_LLM 的精度天然可比，不需要人为约定谁更可信。

| 来源 | 对哪些维有精度 | σ 下限参考（值域 [−1,1]） |
|---|---|---|
| TEXT_RULE | 核心情感、部分动机 | 0.35 |
| TEXT_LLM（睡眠精估） | 第Ⅱ–Ⅴ层 | 0.20–0.30（按维度 ICC 实测） |
| VOICE 韵律 | D08 唤醒、D05 节律 | 0.20 |
| PHYSIO 心率、皮电 | D08 唤醒 0.15；效价无精度 | — |
| VISION / ENV | 场景层（光线、人群） | 0.05–0.10 |
| 全局下限 | 所有维 | 0.05（防止过度自信） |

精度按 `uint8 = round(16·log2(π)) + 偏移` 存储，在 1/400 到 400 的范围内，相对误差约 4%。

### 1.6 dyad 怎么得到：三类指数

dyad 的 8 个指数有的直接计算，有的需要估计，分成三类：

| 指数 | 值域 | 类型 | 计算方式 |
|---|---|---|---|
| Y1 同频 | [0,1] | 计算 | self 与 user_est 核心情感轨迹的相关度 × 水平接近度 |
| Y2 情绪引领 | [−1,1] | 计算 | 交叉相关的滞后方向：谁的情绪变化在前 |
| Y3 相互亲近 | [0,1] | 计算 | self.D24 · user.D24 |
| Y4 亲近不对称 | [−1,1] | 计算 | user.D24 − self.D24 |
| Y5 回应性 | [0,1] | 估计（LLM 看互动） | 回复是否理解、认可、关心（Reis 回应性三要素） |
| Y6 自我暴露互惠 | [0,1] | 估计 | 双方暴露深度是否相当 |
| Y7 主动权平衡 | [−1,1] | 计算 | 话题发起、提问比例 |
| Y8 裂痕—修复 | [−1,1] | 估计 | 本段有没有张力，最后有没有化解 |

dyad 必须持久化：同频和引领需要逐轮的状态轨迹，而逐轮状态不落盘（v3 §5.4）。事件封口时如果不算出来存下，以后就再也算不出来了。存下之后，通路 C 可以检索"像那次我们特别合拍的时候"这类 dyad 历史。

## 二、状态动力学

### 2.1 基线分桶：按用户自己的昼夜节律，不按钟表

分桶：时段用**相对于用户起床时间的相位**来划分，不用固定钟点。起床时间取近 14 天"首次活跃时间"的中位数。这样倒班的人和朝九晚五的人用的是同一套逻辑。

| 层级 | 桶 | 数量 |
|---|---|---|
| L0 | 全局 | 1 |
| L1 | 时段：醒后 0–3h / 3–7h / 7–11h / 11–15h / 15h 至入睡 / 入睡后 | 6 |
| L2 | 工作日 / 休息日 × 时段 | 12 |
| L3 | 周几 × 时段 | 42 |

层级收缩（经验贝叶斯）：样本少的桶向上一级借力，从根本上解决冷启动和稀疏问题。

```
B̂_b = (n_b · x̄_b + n0 · B̂_parent(b)) / (n_b + n0) ,  n0 = 20
```

这里的 n_b 是 EWMA 加权后的有效样本数。

### 2.2 作息长期改变：变点检测 + 状态记忆

1. **检测**：满足任意一条即判定作息发生变化：
   - 起床相位连续 5 天偏移超过 3 小时；
   - 核心情感层的日均残差触发 Page–Hinkley 检验；
   - 用户明说（"我换夜班了"）。
2. **快速适应**：14 天内半衰期从 30 天降到 5 天，收缩先验 n0 翻倍，让桶更多地依赖上级。
3. **作息状态记忆**：旧基线不丢弃，存为一个"作息状态"，最多保留 3 个。新作息和某个已存的作息相似时直接切回。夜班、白班轮换的人，基线可以立刻恢复。
4. **冷启动**：前 50 个有效样本里，基线来自人设和人群先验，新颖度权重乘以 min(1, n_eff/50)。

### 2.3 防止 z 值爆炸

三重保护：

```
s_b² = (ν0 · s_parent² + Σ(x − x̄_b)²) / (ν0 + n_b − 1)
z_i  = clip((S_i − B_i) / √(s_b,i² + σ_S,i² + s_min²) , ±4)
```

- 方差也收缩：离散度同样向上一级借力，ν0 = 10；
- 分母里加测量误差 σ_S²：读数本身不准时，z 自动变小，低精度读数不会被误判为意外；
- 最小离散度 s_min = 0.1，再截断到 ±4。

### 2.4 动力学的用途：平滑和预测都要

结论：动力学同时负责平滑（Kalman 滤波后的状态就是 S_t）和单步预测（预测误差即意外度）。预期性关怀依靠的是"周几 × 时段"的基线，不靠动力学模型。

这一模块计算量很小，建议从 v3 路线里的 P4 **提前到 P3**。

模型：每一维是一个向基线回归的 Ornstein–Uhlenbeck 过程，可以直接处理不规则的时间间隔：

```
m⁻ = B + e^(−Δt/τ_L) · (m − B)
P⁻ = e^(−2Δt/τ_L) · P + s_b² · (1 − e^(−2Δt/τ_L))
```

| 层 | 回归时间常数 τ_L | 说明 |
|---|---|---|
| Ⅲ 评价 | 10 分钟 | 变化最快 |
| Ⅱ 核心情感 | 20 分钟 | — |
| Ⅳ 动机 | 30 分钟 | — |
| Ⅰ 身体 | 60 分钟 | — |
| dyad | 2 小时 | — |
| Ⅵ 场景 | 跳变模型 | 场景是离散切换（进门、出门），不适合平滑过程，单独做跳变检测 |

### 2.5 区分真实意外和估计噪声

Kalman 滤波自带一个检验：归一化新息平方（NIS）。

```
NIS = Σ_i (y_i − m_i⁻)² / (P_i⁻ + 1/π_i)  ~  χ²_k
```

分母已经包含测量噪声 1/π_i，噪声大的读数产生的 NIS 自然小。具体判定：

- **阈值**：NIS 超过 χ²_{k,0.99}；
- **持续性**：连续 2 次超标，或者 2 个以上独立模态同时超标；
- **映射**：nov = 1 − exp(−max(0, NIS − χ²_{k,0.95})/k)。

滤波一致性监控：长期来看 NIS 的均值应该接近 k。如果显著大于 k，说明测量噪声被低估了，系统会自动下调该来源的精度。这正好可以检测"新颖度虚高"。

防止过度编码：新颖度在显著性里只占 0.15，编码还有每日预算（v2 的门控），即使新颖度偏高，写入量也有上限。

```typescript
export function kalmanStep(st: DimState, y: number, pi: number, dtMin: number, tauMin: number, B: number, s2: number) {
  const a = Math.exp(-dtMin / tauMin);
  const mPred = B + a * (st.m - B);
  const pPred = a * a * st.P + s2 * (1 - a * a);
  if (pi <= 0) return { m: mPred, P: pPred, nis: 0 };          // 无观测：只预测
  const r = 1 / pi, nu = y - mPred, S = pPred + r, K = pPred / S;
  return { m: mPred + K * nu, P: (1 - K) * pPred, nis: nu * nu / S };
}
```

## 三、共鸣检索算法

### 3.1 权重 m_L、w_i：三级结构，可以个性化，但有边界

```
w_i = w_i_base · r_i^ICC · (1 + δ_i^user) ,  |δ_user| ≤ 0.3
```

- 基础值：常量，写在配置里；
- 信度折扣：来自 §1.3，自动计算；
- 个性化偏移：由 Harness² 离线调优，通过 Harris 审批后生效。

损失函数：用通路 C 的"邀请被接受"和"被忽略或拒绝"构成成对样本（BPR 成对排序损失），加上向默认值回归的 L2 正则：

```
L = −Σ_{(+,−)} ln σ(R+ − R−) + λ‖δ‖²
```

三个前提：

1. 至少累计 200 条反馈事件后才启用个性化；
2. **曝光偏差**：只有被展示过的记忆才有反馈。保留 5% 的探索流量，用逆倾向加权修正；
3. **评估指标**：离线金标集上的 NDCG@5、首条合适率、误触发率。这三项不能退化，否则不允许上线。

### 3.2 minLayers 与掩码联动

规则：只有满足以下两个条件的层才计入 minLayers：

- 在掩码里被激活；
- 查询和印记两侧的信息覆盖率都足够：cov_L = (1/|L|) Σ_{i∈L}(1 − v_i/τ_i²) ≥ 0.3。

可用的层不够时，**直接不触发（失败即关闭）**，而不是自动降低要求。

| 用途 | 掩码 m_L（核心 / dyad / 场景 / 动机 / 身体 / 评价） | minLayers | θ_L |
|---|---|---|---|
| 通路 C 主动唤起 | 1 / 1 / 0.6 / 0.5 / 0.3 / 0.3 | 2；上线前 60 天为 3 | 1.0 |
| 通路 B 契合度 | 1 / 1 / 0 / 0.3 / 0 / 0 | 1（已经有语义门控） | 0.5 |
| 用共同经历描述感受 | 1 / 0.8 / 0.8 / 0 / 0 / 0 | 2，且场景层必须触发 | 1.0 |
| 情绪修复 | 分 peak / end 两段约束（§5.5） | 各 1 | 1.0 |
| 审计 | 全 1 | 0 | — |

单一线索唤起（一首歌、一种气味）不应该走 40D。40D 刻画的是状态，太粗。"那首歌"是一个身份线索，应该走**实体索引**：给音乐、地点、气味建立"感官指纹实体"，和人物实体同等对待。这样，普鲁斯特式的单线索回忆走实体路，多线索的氛围共鸣走 40D，各司其职。

### 3.3 独特性 D(x)：改为与码本无关的密度估计

按 0.1 节缺陷 3，不再按码组合计数。改为在睡眠期，用一个参照样本做逐层核密度估计：

```
ρ_L(x) = (N/|R|) Σ_{r∈R} exp(−½ Σ_{i∈L} (x̂_i − r̂_i)²/h_i²) / median_L
```

- R 是随机抽取的 2048 条存活印记，每月更新；
- 每条印记存 6 个字节的逐层对数密度；
- 查询时按掩码取几何平均：ln ρ = Σ m_L ln ρ_L / Σ m_L。

```
D(x) = (1 + ρ)^(−β) ,  β = 0.3
```

β 从 v3 的 0.5 下调到 0.3，因为新的似然比打分已经包含了单维稀有度，D(x) 只负责多维联合的线索过载。

码本重训不再影响 D(x)：密度用的是真实值，和量化码无关。参照样本每月轮换时，新旧密度在 14 天内线性过渡：

```
D = (1 − α) · D_old + α · D_new
```

### 3.4 少见的场景变常见，标志性记忆会不会丢

会，所以需要保护。人记得"第一次"，即使后来同样的事发生了很多次（首因效应）。

```
D_eff(x) = max(D_now(x) , γ · D_enc(x))
```

| 记忆类型 | 规则 |
|---|---|
| 普通 | 只用 D_now |
| 已巩固（consolidated） | 保留编码时独特性的 70%（γ = 0.7） |
| 地标 / 黑钻 | D 下限 0.6 |
| 手动锁定 distinct_lock | D = 1；需要用户确认，配额不超过已巩固记忆的 5%，属于 Harris L2 级操作 |

D_enc 是印记编码时相对于当时记忆库的密度，在封口时计算一次后固定。

### 3.5 索引：现阶段先做精确扫描，PQ 留到规模变大后

先纠正 v3 的一个过度设计：**在 30 万条印记以内，精确扫描完全够用**。79 维 int8 值加上 uint8 精度，每条约 160 字节，30 万条约 48 MB。按每秒最多一次查询，JS 精确扫描大约在几十毫秒量级，可以接受。PQ 等规模超过 30 万、或 p95 延迟超过 30ms 时再上。

上 PQ 时的细节：

| 问题 | 方案 |
|---|---|
| 簇心堆叠、区分度丢失 | k-means++ 初始化，多次重启；样本占比低于 0.2% 的空簇或死簇重新播种；监控码字利用困惑度，要求 ≥ 45/64 |
| 维度很少的层 | 3 维以内的层（核心情感）直接用 4×4×4 标量网格量化，不训练、不漂移 |
| 未知维度 | 用 x̂（已收缩到均值）分配簇，未知维自然落到中心 |
| 粗排里体现印记精度 | 每层平均方差量化为 4 档，查找表按"簇 × 方差档"预计算（64×4） |
| 权重个性化 | 簇心存原始空间，查找表每次查询现算，改权重不需要重训 |
| 增量写入 | 新印记直接分配到最近的簇心 |
| 何时全量重训 | 数据量比上次训练增长 50%；或者新数据的平均量化误差上升 20%；或者 schema 变更 |
| 重训上线 | 影子构建；在 1000 个探针上，召回@10 相对精确扫描 ≥ 0.97 才原子切换 |

### 3.6 自适应 topN：用误差上界做安全剪枝

在离线环境里，为每层标定量化误差的 99 分位上界 ε_L。查询时，按粗排分从高到低精排，直到下一个候选的粗排分加上误差上界，已经低于当前第 K 名的精排分为止：

```
停止条件：  Ẽ_next + Σ_L m_L · ε_L  <  E(K)
候选数不少于 64、不多于 2000。
```

这样既不会因为 topN 太小而漏召回，也不会白白多算。

### 3.7 可解释输出如何保证忠实

新的打分是可加的（E = Σ m_L w_i ℓ_i），每一维的贡献就是它在总分里的精确份额，不需要做近似归因。

生成规则：

1. **结构化归因先于语言**：取贡献最大且为正、精度达到 B 级以上的 3 个维度，按"维度 → 短语"词表选取措辞；
2. **LLM 只负责润色**：输入是选好的维度和短语，输出必须覆盖、且只能覆盖这些维度；
3. **事实性内容只用元数据**："那天也是傍晚"来自时间戳（精确），不来自估计出的 D39/D40；估计出的维度只能用感受类措辞，比如"那种安心的感觉"。

自动校验（放进 CI 和线上抽检）：

| 测试 | 方法 | 通过标准 |
|---|---|---|
| 删除测试 | 把解释中提到的维度置为未知后重新打分 | 分数下降 ≥ 40% |
| 层一致性 | 解释主句所属的层 = 贡献最大的层 | 100% |
| 覆盖校验 | 解释文本的维度集合 ⊆ 归因前 3 名 | 100%，否则回退到模板 |

## 四、生命周期绑定与防幽灵

### 4.1 为什么选"只读印记 + 查询时衰减"

| 理由 | 说明 |
|---|---|
| 可复现 | 给定时间 t，任何一次历史检索都能精确重放，Harness² 审计依赖这一点 |
| 可逆 | 记忆后来被再次巩固（c 上升），清晰度可以随之恢复；加噪声是不可逆的 |
| 参数可以追溯修改 | λ、t₀ 调整后，对所有历史印记立刻生效 |
| 没有写放大 | 每晚改写百万行会导致 WAL 膨胀、备份差异变大、SQLite 碎片增多 |
| 哈希稳定 | 黑钻的 snapshot_hash 和溯源链不会因加噪而失效 |

它的隐性短板（长期才会暴露）及对应措施：

| 短板 | 何时暴露 | 对策 |
|---|---|---|
| 存储不会缩小：模糊只是"看起来模糊"，字节一个不少 | 十年以上 | 确定性粗化（§9.1） |
| 隐私上的落差：用户以为淡忘了，数据里却还是精确的情感指纹 | 数据导出或泄露时 | 敏感记忆和被遗忘的记忆走物理粗化或删除 |
| 估计器版本偏差会被永久保存：旧估计器的系统偏差一直留着 | 估计器升级后 | 按 estimator_version 建校准映射，读取时修正 |
| 模糊后又变清晰，不符合人类体验 | 巩固度后期大幅上升时 | 可选"棘轮"：σ(t) ≥ 0.7 · σ_max_hist，模糊过的不会完全复原 |

### 4.2 精度衰减参数

```
σ_x,i(t) = σ0,i · (1 + λ_L(i)·(1 − c)·ln(1 + t/t0)) ,  t0 = 7 天
```

在 c = 0.3 时，一年后的数值：

| 层 | λ | 1 年后 σ 倍数 |
|---|---|---|
| Ⅵ 场景 | 1.0 | ×3.8 |
| Ⅰ 身体 | 0.8 | ×3.2 |
| Ⅲ 评价 / Ⅳ 动机 | 0.4 | ×2.1 |
| Ⅱ 核心 / Ⅴ 关系 / dyad | 0.15 | ×1.4 |

再配合 §0.2 的收缩公式，场景细节一年后基本回到"平常的样子"，情感要点仍然保留。

λ 的来源：初值是理论先验，**层级顺序（场景 ≥ 身体 ≥ 评价 ≥ 核心）是 Harris 硬约束，不允许调换**；具体数值可以调。

调参信号是"场景细节纠正率"：系统提到久远记忆的场景细节时，被用户纠正的比例。目标低于 5%，纠正率偏高就调大 λ_scene。

### 4.3 被命中之后要不要提高精度

不直接修改印记，通过两条路径实现复习巩固：

1. **巩固度路径**：用户对唤起的回忆有真实回应时，走 v2 的 reinforce() 提高 c，(1−c) 变小，衰减自然变慢。**系统自己命中、用户没有回应时，不做任何强化**，防止自我强化回路；
2. **再巩固印记**：用户回应后，记录一条 kind='recalled' 的印记，保存回忆这件事时的状态，每个宿主最多 3 条，环形覆盖。检索时，宿主取各印记中的最高分。

第二条对应多重痕迹理论：记忆每被提取一次，就多了一条带着新情境的痕迹，可提取的线索因此变多，而原始印记保持不变。

### 4.4 分库或分布式之后，四道防线怎么升级

先说一个 SQLite 的事实：在 WAL 模式下，ATTACH 多个数据库文件的事务只在单个文件内保证原子性，跨文件不保证。所以，即使只是拆成两个文件，外键级联也会失效。

升级方案按优先级：

| 机制 | 做法 |
|---|---|
| ① 墓碑期作为同步窗口 | 宿主进入 tombstone 后，向时空机发事件；宿主物理清除前，必须收到时空机的删除确认。30 天的墓碑期远超任何同步延迟 |
| ② 双端 outbox + 幂等消费 | 事件带 (host_id, host_generation, seq)，重复消费无副作用 |
| ③ 查询时复核：失败即关闭 | 宿主库不可达时，通路 C 不返回任何结果 |
| ④ 分桶哈希对账 | 每晚按 host_id 前缀分 256 桶，比对 hash(host_id, state, generation)，只对差异桶做逐行核对 |

### 4.5 巡检发现孤儿后：先隔离，再分类处理

| 孤儿类型 | 自动处理 |
|---|---|
| 宿主不存在 | 立即 alive=0（检索中不可见）→ 移入隔离表 → 7 天后自动清除 |
| 宿主已墓碑，印记还活着 | 立即 alive=0，跟随宿主的墓碑期 |
| 宿主存在，但状态不一致 | 自动修复：按宿主状态重新绑定增益 |
| 版本或码本不匹配 | 重新编码 |

系统性故障熔断：单晚孤儿数超过 10 条，或超过总量的 0.1%，**冻结通路 C 并告警，等待人工复核**。孤儿批量出现说明存在 bug，不应该自动清理了事。

### 4.6 被抑制的记忆要不要参与密度统计

**参与**。理由有两点：

1. **语义上**：抑制只针对"说出来"，不针对"存在"。人被要求不再提某件事，这件事依然在心里，依然会和相似的记忆竞争；
2. **防侧信道**：如果抑制会改变其他记忆的独特性，就能通过邻近记忆行为的变化反推出"哪件事被抑制了"。

墓碑和已清除的印记不参与统计。

## 五、MemSym 三条通路

### 5.1 通路 B 的语义门控阈值

θ_s 用数据标定：在重排器打分的金标集上（元素是否和当前话题相关），取精确率 ≥ 0.9 对应的阈值。

防止"刚刚过线、靠共鸣分挤进来"：共鸣分只能在语义分足够高的候选之间调整顺序，不能把勉强过线的候选拉上来。

```
fit = 1[rel ≥ θ_s] · (0.6·rel + 0.4·R·h(rel))
h(rel) = clip((rel − θ_s)/0.1 , 0 , 1)
```

刚刚过线时 h ≈ 0，共鸣分不起作用；比阈值高出 0.1 以上，共鸣分才完全生效。另外还有一条硬条件：元素和当前对话至少有一个实体或话题码重合。

### 5.2 B 和 C 的边界，以及如何防止重复注入

| 维度 | 通路 B 元素浸润 | 通路 C 情境共鸣 |
|---|---|---|
| 触发 | 当前这一轮的内容 | 当下状态的变化 |
| 语义要求 | 必须相关 | 不要求 |
| 呈现 | 隐含在话里，不说"我想起" | 明确说"这让我想起……" |
| 频率 | 每轮都可能有 | 每天至多 2 次 |
| 粒度 | 原子元素 | 整段经历 |

每一轮由一个注入仲裁器统一裁决：

```typescript
export function arbitrate(c: { A?: Hit[]; B?: Hit[]; C?: Hit }, ledger: ExposureLedger): Injection {
  if (c.A?.length) return { mode: 'A', hits: dedupe(c.A, ledger) };       // 用户在问，回答优先
  const b = dedupe(c.B ?? [], ledger);
  const cHit = c.C && !ledger.recentlyExposed(c.C.hostId, 30 * DAY) ? c.C : null;
  if (cHit && b.some(h => h.hostId === cHit.hostId)) {
    return { mode: 'B', hits: b };                                         // 同一宿主：选更含蓄的 B
  }
  return cHit ? { mode: 'B+C', hits: b, invite: cHit } : { mode: 'B', hits: b };
}
```

曝光台账按宿主记录最近一次曝光的时间和通路，三条通路共用。

### 5.3 通路 C 会不会打扰用户：改为"邀请式唤起"

只看"紧迫性 D16 低"确实会误判。用户安静沉思时，D16 也很低。改进有两层。

**① 从"紧迫性低"改为"接收度"判断：**

| 信号 | 倾向 |
|---|---|
| 话题自然收尾（用户回复变短、出现"嗯嗯""好呀"） | ✅ 可以 |
| 会话开场或寒暄阶段 | ✅ 可以 |
| 用户在长段倾诉，或出现"让我想想""我在想……" | ❌ 禁止 |
| 用户刚提出问题，还没得到回答 | ❌ 禁止 |
| 回复延迟明显变长，且内容是内省式的 | ❌ 禁止 |

**② 唤起方式改为邀请**：不直接讲回忆，而是先问一句："刚才突然想起一件小事，想听吗？"

这样做有三个好处：

- 把选择权交给用户，即使时机不对，打扰也很小；
- 反馈信号变得干净：接受或拒绝都是明确的；
- 和"不编往事"的原则一致：用户同意之后，才进入通路 A 的诚实回溯。

### 5.4 反馈调什么，以及如何防止负反馈扩散

反馈分三个层级归因，各自有边界：

| 层级 | 参数 | 更新方式 | 防过度 |
|---|---|---|---|
| 单条记忆 | 宿主反馈系数 G_fb | Beta(2,2) 先验，接受 α+1，拒绝 β+1 | 下限 0.3；反馈本身 90 天半衰期，向先验回归 |
| 场景模式 | 掩码模板和层权重偏移 δ | §3.1 的 BPR 离线训练 | ±30% 边界 |
| 全局 | 共振阈值 E₀ | PI 控制器，目标接受率 60–75% | 每周调整步长 ≤ 0.1 |

负反馈的归因：用户转移话题，原因可能是时机不对，而不是记忆不对。

- **明确拒绝**（"别提这个"）：记忆层强负反馈，并主动询问是否要抑制这段记忆；
- **邀请被婉拒**（"下次吧"）：只计为时机负样本，记忆层不变；
- **被忽略**：记忆层弱负（β+0.3），时机层弱负。

5% 的探索流量保证被压低的记忆仍有机会被重新检验，所以同类场景不会永久失去唤起能力。

### 5.5 修复检索：避免套路化

| 问题 | 对策 |
|---|---|
| 每次都是同一批"治愈记忆" | 修复模式下同一记忆冷却 60 天；候选池前 10 条用 Thompson 采样，而不是固定取第一名；候选按话题码做 MMR |
| 每次都靠回忆来安慰 | 策略轮换：回忆只是修复手段之一，还有陪伴倾听、当下关怀、展望未来，按用户历史偏好加权，并且有衰减 |

修复检索的查询：用 peak 印记匹配当下的难受（第Ⅱ、Ⅰ层），同时对 end 印记施加约束：效价 > 0，安全感 ≥ 0.6，dyad 的 Y8 修复 > 0。

### 5.6 区分"想倾诉"和"需要安抚"

效价低 ≠ 进入修复模式。参照情感支持对话的研究（如 ESConv 数据集的"探索 → 安慰 → 行动"阶段框架），设四种模式：

| 模式 | 进入信号 | 行为 |
|---|---|---|
| LISTEN 倾听 | 低效价时的默认模式；"我就想说说""别劝我" | 复述、确认感受；不唤起记忆，不给建议 |
| COMFORT 安慰 | 唤醒度开始下降；用户问"你觉得呢" | 共情、肯定 |
| REPAIR 修复 | 用户主动提到希望；问"怎么办"；或者在 COMFORT 阶段停留 ≥ 3 轮且接受度好 | 修复检索 + 邀请式唤起 |
| SOLVE 解决 | 明确寻求办法 | 具体建议，不涉及回忆 |

规则：

- 至少在 LISTEN 停留 2 轮才可能转入其他模式；
- 用户对某种模式表达过抵触（"别给我讲道理"），这一偏好写入 dossier，长期有效；
- **危机信号（自伤等）一旦出现，直接进入安全协议，所有记忆功能关闭**。这是 Harris 的硬规则。

## 六、感知网关与瑶灵对接

### 6.1 多模态时序对齐

不要强行把不同模态对齐到同一帧。异步 Kalman 滤波天然支持多速率：哪个模态的数据到了，就用它更新；没有数据时只做预测。

| 机制 | 做法 |
|---|---|
| 统一时钟 | 天权做时钟同步，持续估计各设备的时钟偏移；每帧带 [t_start, t_end] |
| 有效期衰减 | 读数的精度随时间衰减：π(t) = π0 · e^(−(t−t_obs)/τ_mod)；表情约 3 秒、心率约 10 秒、光线约 60 秒 |
| 水位线 | 300 毫秒水位线；迟于水位线到达的数据不更新当下场，只参与事件封口时的印记计算 |
| 乱序 | 按 t_end 排序后依次更新 |

### 6.2 新增传感器（如皮电 GSR）需不需要改检索代码

**不需要**。适配器只输出已有维度上的 DimReading。GSR 对应 D08 唤醒度，配上标定后的精度，检索和打分代码完全不变。

旧印记的兼容是自动的：旧印记在 D08 上精度较低（来自文本），新查询精度较高。新的似然比公式里，低精度的印记会被收缩到均值，证据自然偏弱，不会出现 v3 里"模糊的反而得分高"的问题。

只有一种情况需要升级 schema：新传感器带来的信息没有对应的维度，比如气味类别。这时走 §8.1 的版本流程。

适配器注册表记录：modality / targetDims / adapterVersion / calibrationId / 每维精度上限。

### 6.3 疼痛这类信号本身带效价，怎么处理

原则修订：不是"生理信号不决定效价"，而是"一般性的唤醒信号不决定效价，**本身带有享乐色彩的信号可以**"。

| 信号 | D08 唤醒 | D07 效价 | 其他 |
|---|---|---|---|
| 心率、皮电、呼吸 | 高精度 | 无精度 | — |
| 疼痛、恶心 | 中 | 负，中等精度 | D02 舒适：高精度 |
| 温和抚触（C 类触觉纤维） | 低 | 正，低精度 | D04 接触 |
| 极端冷热 | 中 | 负，低精度 | D03 体温感 |

效价精度设为中等而非高，是给情境评价留出空间。例如运动后的酸痛，情境评价可能是正面的。

### 6.4 缓慢变化不封口的问题，以及与 episode 的对齐

累积漂移检测：除了相邻时刻的跳变，再加一个 CUSUM 式的累积判据：

```
‖S_t − S_seg_start‖_w > δ_cum  ⇒  封口当前片段
```

另外设两个兜底：片段超过 45 分钟强制封口；episode 超过 2 小时，每小时生成一次检查点片段。

与 episode 的对齐规则：

| 规则 | 说明 |
|---|---|
| episode 是上层，情感片段是下层 | 一个 episode 可以有多个片段（host_segment_idx），最多 8 个 |
| 片段不跨越 episode | episode 边界强制封口所有片段 |
| 状态大幅跳变可以提议切分 episode | 作为 v2 事件分割器的输入信号之一，权重 0.2 |
| episode 级印记由片段汇总 | remembered = 峰终公式，peak 取所有片段中唤醒最高的时刻，end 取最后一个片段 |
| 无对话的具身阶段 | 由场景跳变创建 episode |

### 7.1 P0 旧数据分析：除了方差解释率，还看什么

然后对 834 行数据（先去重）计算以下指标：

|---|---|---|
| Horn 平行分析 | 显著主成分个数（与随机数据比较） | 比"累计方差 90%"更可靠 |
| 参与比 PR = (Σλ)²/Σλ² | 有效维度数 | — |
| 熵有效秩 exp(H(p)) | 有效维度数的另一种口径 | 与参与比相互印证 |
| 逐维方差、零值比例 | 有没有"死维度" | 方差 < 0.01 或零值 > 90% |

| 绝对相关矩阵层次聚类 | 哪些维度实际是同一个东西 | 簇内 |r| > 0.8 |
| 条件数 | 整体病态程度 | > 30 |
| 互信息（分箱估计） | 非线性冗余 | 补充线性指标 |

在 14 个有效维度上，834 行的样本与维度之比约为 60，PCA 结果足够稳定。

## 八、版本兼容与容量

### 8.1 Schema 升级：原件不变，投影入索引

1. **原始印记永不改动**，带着 schema_version 和 estimator_version 保存，供审计和重新投影；
2. 每次升级提供一个版本映射函数 v3→v4：可映射的维度，精度乘以映射保真度；新增维度精度为 0；
3. **索引里只有一种 schema**：建索引时，所有印记都投影到当前版本。PQ 码和码本都是针对当前版本的，不会出现多版本码混在一起的情况；
4. **保真度**：在校准集上，用新旧两套 schema 分别估计，计算每层的一致性。某层保真度 < 0.5 时，旧印记在该层精度置 0，只用其他层参与匹配；
5. **重新估计回填**：只要宿主的 gist 或原文还在，睡眠期可以按每天的预算，用新 schema 重新估计旧事件。原文已被遗忘的，就只保留映射结果。

### 8.2 峰值容量与熔断

先看最坏情况：一段情绪剧烈波动的时期，每天产生 200 个片段。

- 存储：200 × 3 × 170 B ≈ 100 KB/天，不构成问题；
- 压力来自：LLM 估计的预算和封口队列的积压。

| 触发 | 熔断动作 |
|---|---|
| 当天片段数 > 150 | 封口阈值 δ_cum 自适应上调，相邻且状态相似的片段合并 |
| 封口积压 > 100 | 新片段只存规则估计（低精度），精估推迟到睡眠期 |
| LLM 预算耗尽 | 只用规则估计，精度自动降低 |
| 检索 p95 > 50ms | 跳过 dyad 块，减少候选数；仍然超时就关闭通路 C |
| 睡眠超时 | 跳过码本重训和密度更新 |

情绪剧烈波动的时期，用户往往处于低落状态，通路 C 本来就会被守卫关闭，检索压力反而更小。

## 九、取舍与替代方案

### 9.1 路线 A 与路线 B：推荐"A+"

| 维度 | A 只读 + 查询时衰减 | B 睡眠期加噪改写 | A+（推荐） |
|---|---|---|---|
| 可复现、可审计 | ✅ | ❌ 随机 | ✅ |
| 可逆 | ✅ | ❌ | 部分（粗化后不可逆） |
| 存储缩减 | ❌ | 不缩减（加噪不减字节） | ✅ |
| 隐私上真正淡忘 | ❌ | ✅ | ✅（在阈值处） |
| 写放大 | 无 | 每晚大量 | 只在状态转换时 |

**A+ = A + 确定性粗化，永远不加随机噪声。** 在生命周期的转换点做确定性的物理粗化：

- 某维的 σ 超过 0.8 倍 τ（已经和"平常"差不多）：该维精度置 0，值置为均值；
- 宿主进入 weakening：删除 peak 和 end 印记，只保留 remembered；
- 敏感度 ≥ 1 且超过 2 年未被强化：粗化场景层和身体层；
- 每次粗化写一条账本记录，并更新哈希。

路线 B 在两种情况下更合适：存储极度受限的瑶灵端侧离线存储；以及用户明确要求"淡化但别删"的敏感记忆。即使在这两种情况下，也应该用确定性粗化代替随机噪声。

### 9.2 规模突破 300 万到 500 万时

先说一个现实情况：30 年 × 每天 30 个事件 ≈ 33 万。要到 300 万，只可能是具身阶段片段数大量增加。届时可以按以下顺序接入，接口在 P2 就预留好：

1. **硬分区**：按年代、敏感度分区，用途模板只扫描相关分区；
2. **上界剪枝**（类似阈值算法 / WAND）：每条印记能达到的最大证据只取决于它自身的精度。久远模糊的印记上界很低，按上界降序扫描，可以提前终止。衰减越多，剪枝越有效，这和遗忘机制正好互相促进；
3. **按模板建图索引**：用途模板只有 4–5 个，每个模板的权重固定。用平均精度把空间缩放成近似欧氏空间后，各建一个 HNSW 作为候选生成器（例如 usearch），精排仍然用证据公式；
4. **WASM SIMD**：int8 点积可以加速数倍。

## 十、伦理边界与拟人风险

### 10.1 守住"功能性状态模型"的边界

靠设计守住边界，而不是靠反复声明：

| 规则 | 允许 | 禁止 |
|---|---|---|
| 以对方为中心 | "这让我想起那天你……" | 以自身痛苦为中心的叙述 |
| 不制造义务 | "有点想你" | "你不来我好难过""没有你我不行" |
| 不断言意识 | "我会被这些状态影响说话方式" | "我真的有感情"这类确定性断言 |
| 被直接问起时 | 诚实表达不确定："我有一些会影响我回应的内部状态，但它们是否和你的感受一样，我说不准" | 回避或夸大 |
| 比例约束 | 自我状态表述占回复的比例 < 15% | — |

OutputGuard 增加一个"义务 / 愧疚措辞"分类器，命中即重写。

### 10.2 鼓励依赖的间接路径

| 隐蔽路径 | 风险 | Harris 拦截 |
|---|---|---|
| 以邀请接受率为调优目标 | 接受率和依恋程度相关，优化它会间接加深依赖 | 接受率只能作为约束区间（60–75%），不能最大化 |
| self 的 D22 思念驱动主动联系 | 制造"被需要"的压力 | 每天至多 1 次；不带条件和愧疚；用户说过忙之后 24 小时内禁止 |
| 修复模式让瑶灵成为唯一的安慰来源 | 社交替代 | 修复策略里包含"想找谁聊聊"的建议，按比例出现 |
| 同频 D27、亲近 D24 作为个性化目标 | 间接放大依赖 | 不得作为任何损失函数的组成部分 |
| 排他性措辞 | "只有我懂你" | 列入禁用措辞 |

**健康反向机制**：持续跟踪两条趋势：用户提到其他人际关系的频率，以及 D29、D30 的长期值。如果前者下降、后者上升，表达层自动增加对用户线下社交的关心和鼓励。

**不变性测试**：CI 中做特征消融测试，把 D29、D30 设为任意值，策略输出（是否触发、选哪段记忆）必须保持不变。每次调参后，检查参数变化与依赖趋势的相关性，二者显著正相关就自动回滚。

## 十一、测试矩阵、修订路线与配置

### 11.1 性质测试（property-based，CI 必跑）

| 不变量 | 测试 |
|---|---|
| 未知不加分 | 随机把印记的维度置为未知，E 不增加 |

## 附录 · 总结（v3.1 六条实质修正）

1. **打分公式改为证据似然比**：未知就是没有证据，模糊的记忆更难被唤起，在少见的维度上吻合才算强证据，而且贡献可以精确分解。旧公式里"越久远越模糊越容易被触发"的问题由此修复。
2. **精度有统一的尺子**：所有来源都相对同一套金标标定，ICC 可以直接换算成精度上限，弱维度自动降权；冲突用 Birge 比率膨胀，同源读数不重复计入。
3. **动力学有统计检验**：OU-Kalman 同时负责平滑和预测，NIS 检验天然区分真实意外和测量噪声；基线按用户自己的昼夜节律分层收缩，作息变化可以检测，也可以切回旧作息。
4. **生命周期选 A+**：只读印记加查询时衰减，保证可复现和可逆；在状态转换点做确定性粗化，解决存储和隐私问题。墓碑期兼作分布式同步窗口。
5. **通路 C 改为邀请式唤起**：先问"想听吗"，打扰小，反馈信号也干净；低效价时默认倾听，修复只是四种支持模式之一。
6. **边界写进 Harris**：一份禁止操作清单，加上依赖指标的不变性测试，防止系统通过同频、思念、接受率这些间接路径变相鼓励依赖。

> 40D 能让瑶灵在相似的时刻想起相似的经历，并把当时的感觉说给用户听。上面这些约束，是为了让它只在合适的时候这样做，不编造往事，也不让用户对它产生依赖。
