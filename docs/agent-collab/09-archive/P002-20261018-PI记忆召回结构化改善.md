## 关键结构决策（全部非词表补丁，判据/权威层修正）

1. **隐私权威唯一化**：会晤检索路径的文字模式隐私判据（isIntimateAboutOthers）整体退役——
   八路上游逐一核查全部 belong_entity_uuid 收敛，filterPrivateConversations（UUID+来源+ACL
   deny-by-default）保留为权威闸门。文字层是 UUID 机制的前朝兜底，只能误杀（实测一次杀 11 条
   当前实体自己的记忆）或重复。
2. **事件召回=覆盖职责**：锚点通道与钙化槽分工——通道不复用钙化序（低钙事件锚点会结构性死亡），
   时间分层双端取数 + 沉淀窗排除当前对话回声（自我污染回路：她每说一次"记不着"就生成新讨论锚点）。
3. **时间轴真序**：锚点 seq_pos 为负（ADR-010），seq ASC 实际取"最新讨论回声"——
   earliestMemoriesByTime（created_at ASC + seq_pos>0）为唯一真源，两调用方收编。
4. **时间注入=环境元数据**：三处注入点（core-rules/EntityContextBuilder/chat.ts timeGuard）
   全部从陈述句改元数据字段定性——负面禁令敌不过"现在是X"的陈述句模式匹配（压测实锤）。
