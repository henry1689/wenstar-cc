## 三、任务分配（并行）

### Claude：M层埋点 + exit意图覆盖扩大

**任务1：M层埋点补齐**
- GroupSession.dispatch 内加 module_entry/module_exit 日志
- 与 S4.5 审议时"埋点放唯一调用点"的陈述对齐
- 日志格式参考现有 M 层埋点规范
- 确保 dispatch 的每个 action 类型都有埋点
- 验证：触发 WAKE/JOIN/SPEAK/LEAVE/RESUME/IDLE 都有对应日志

**任务2：exit 意图覆盖扩大**
- 现有 exit 只认四类句式：
  1. 散会|不聊了|不开了|今天就到这儿|先这样|下了|拜拜|再见
  2. ^结束(了|吧|啦)?(会议|对话|会晤|话题|我们|聊天)?(吧|了|啦|~|!|！)?$（整句匹配）
  3. ^(切回|回到|换回|变回)玉瑶$（句尾为玉瑶）
  4. ^(和|跟|找|叫|让)?玉瑶(聊聊|谈谈|...)?$
- 扩大覆盖：
  - "结束，回玉瑶这边" / "结束，回玉瑶" / "结束吧，回玉瑶"
  - "不聊了，回玉瑶" / "散会，回玉瑶"
  - "回到玉瑶那边" / "回玉瑶那边"
  - "找玉瑶" / "叫玉瑶" / "让玉瑶来"
  - 原则：exit 意图 + 玉瑶指向 同时出现时触发退出
- 注意：不要扩大到误判正常对话（如"玉瑶今天怎么样"不应触发退出）
- 加单元测试覆盖新句式

**约束**：
- WS_GROUP_V2 门控（exit 扩大是旧架构 EntityMeeting 的改动，不受开关限制，但要确保不影响新架构）
- tsc=0 + 现有测试全绿
- 行为等价：原有 exit 句式继续有效

### PI：多人会晤生产实测 + V15行号结构性改善

**任务1：多人会晤生产实测**
