# MemSym v3.1 解读研判与落地路线

> 本文件是对《MemSym v3.1 · Field40 情感状态场总纲白皮书》的分层解读与落地对齐结论，供协作区（Claude Code / Harris / Hermes）统一认知基线。
> 与白皮书冲突时，以白皮书正文为准。

---

## 整体研判

Claude Opus 5.5 这份 v3.1 修订，是一次非常扎实、对齐原始设计意图的纠错与闭环。
它抓住了最核心的痛点：**v3 的高斯打分内核数学上自带反向 Bug（越模糊、信息越少，得分越高）**，并且同步补齐了信度校准、贝叶斯融合、记忆生命周期、通路仲裁、瑶灵多模态网关、Harris 守卫红线一整套统计工程框架——不是零散补丁，是自洽的统计认知体系。

---

## 一、最核心的革命性改动：从「向量相似度匹配」→「线索诊断性对数似然比 ℓᵢ」

原本的设想：40D 不是找"长得像"的印记，而是找到**当前这组时空心境线索，唯独能区分开这一段独有记忆**。

- **v3 高斯核缺陷复盘**：缺失维度、记忆衰减模糊之后 σ 变大，反而趋近满分，等于"不知道=高度共鸣"，完全违背仿生遗忘；独特性 ρ 绑定码本，码一改全部失效，基本摆设。
- **v3.1 新逻辑（Nairne 线索诊断性理论）**：每一维打分 = **这条印记，对比用户长期常态背景分布，多大程度上解释现在的状态**。
  - 未知维度：ℓ=0，无证据，不加分 ✅
  - 记忆随时间模糊、向用户常态均值（图式回归）收缩：ℓ 自然压低，越老越难唤起 ✅
  - 罕见取值（海边、特殊情绪、难得的松弛）匹配：证据分拉高；日常普通场景匹配，证据偏弱，天然抑制泛滥唤起 ✅
  - 分值可线性分解归因：后面给人的可解释话术，每一句话都能追溯到是哪几个维度贡献，杜绝幻觉式解释

> 这正是时空机模块最需要的内核，和 DNA 语义链路天然解耦：
> DNA 管语义关联（通路 B）；40D 似然比证据管**情境、时空、心境共鸣（通路 C）**，两条通路各司其职，不会打架。

配套改动：存储结构扁平化，79 维一行（共享场景层 + self + user_est + dyad 关系指数），不再三份冗余场景数据、互相矛盾，存储体积大幅下降。表结构 `scene_imprints_v31` 直接纳入协作区数据库设计文档。

## 二、信度体系：ICC + 贝叶斯融合，解决"不同传感器、不同 LLM 估出来的值能不能放一起算"

这块是之前讨论时的盲区，Opus 把标尺统一了：

1. 不再凭主观定"语音比文本准、生理信号优先级更高"；**全部维度共用同一套金标校准后的精度刻度（方差倒数 π）**。
2. 维度分级 A/B/C：ICC ≥ 0.75 全权重、0.5~0.75 降权、< 0.5 直接退出共鸣打分，只留着做语气表达；难标定弱维度（D13 确定性、D26 被理解感）直接降级、合并、迁移到 dyad 可观测指数（Y5 回应性），不硬扛不可靠的估计。
3. 同源合并 + 冲突惩罚（Birge 比率）：
   - 同一段文本跑出的规则抽取 + LLM 评估，属于同源证据，不能直接叠加；
   - 同一维度多源读数冲突（嘴上平静、心率紧绷），自动膨胀误差、压低整体置信，标记 `expression_mismatch`，交给 Harris 管控：**只温和关心，禁止拆穿、禁止判定用户撒谎**，这条伦理约束非常关键。

> 对瑶灵意义极大：后续摄像头、心率、GSR、触觉传感器接入，只需要写适配器输出标准化 `DimReading`，检索内核一行不改。

## 三、状态动力学：OU 卡尔曼滤波 + 用户个性化基线桶（不是固定钟表时间）

亮点：基线以**用户起床相位**划分时段，支持倒班、作息轮换，最多保留 3 套作息快照，换夜班、换回白班可以直接切基线，冷启动用经验贝叶斯向上借力，解决样本稀疏。

- 每一层独立时间常数 τ：评价最快（10min）、核心情感 20min，身体层慢到 60min，dyad 双人关系轨迹最慢 2h；场景层不做平滑，单独做跳变检测，符合现实。
- NIS 新息卡方检验：区分「真的意外、新颖体验」和「传感器噪声、估计误差」，从根源解决新颖度虚高；新颖度只是编码门控其中一项，还有每日写入预算，防止疯狂写印记。

## 四、记忆生命周期：选定 A+ 路线【只读印记 + 查询时衰减 + 定点确定性粗化】

这个取舍是整篇文档最重要的架构决策，完全贴合审计、Harness² 复盘追溯的需求：

- ❌ **拒绝方案 B**：睡眠期改写、加噪声，随机化之后历史不可复现，Harness² 没法重放审计，哈希溯源断裂；
- ✅ **A+**：原始印记**只读、永不改写**，衰减是查询计算时动态变化的 σₓ(t)；巩固（用户回忆、回应）只修改巩固度 c，不篡改原始印记；
  只有到达长期阈值（σ 足够贴近常态、超 2 年未巩固、敏感记忆）才做**确定性粗化**：精度置 0、值收敛到均值，留下账本和哈希记录，不是随机抹糊。
- **多重痕迹理论落地**：唤起之后用户回应，新增一条 `kind=recalled` 印记，而不是原地修改旧记忆，符合认知科学；系统自己唤起、用户无反馈，**不自动巩固，杜绝自激闭环**。
- **墓碑同步机制**，给以后分布式、分库部署预埋了同步和孤儿巡检四道防线，孤儿批量爆发直接熔断通路 C、告警，不盲目清理。

衰减 λ 层级顺序是 Harris 硬锁：`场景 > 身体 > 评价/动机 > 核心情感/关系 dyad`。
场景细节一年后大幅淡化，但核心情感、双人同频的感受衰减很慢，完美匹配想要的记忆特性：**场景会模糊，刻骨铭心的情绪感受保留很久**。

## 五、MemSym 三条通路仲裁（A/B/C），解决最容易翻车的"乱蹦回忆、打扰用户"

1. **通路 B（语义浸润）**：语义门槛前置，共鸣分只在语义已经足够相关的候选里面微调排序，不能强行把不相关记忆拉进来。
2. **通路 C（情境共鸣，40D 时空机主输出）**：**邀请式唤起**，不再直接抛出回忆；每天上限 2 次，宿主冷却 30 天；
   触发时机不再只看 D16 紧迫性，改用接收度规则：用户倾诉、提问、深度思考时直接禁用；会话收尾、松弛间隙才允许发起邀请："刚才突然想起一件小事，想听吗？"
   反馈分层归因：明确拒绝 = 记忆负反馈；婉拒"下次吧"只归为时机问题，记忆本身不扣分；保留 5% 探索流量防止永久雪藏。
3. **对话四种模式隔离**：LISTEN 倾听 → COMFORT 安慰 → REPAIR 修复 → SOLVE 解决。
   低效价默认先倾听两轮，修复只是其中一种手段，并且修复检索带约束：匹配难受的 peak 印记，同时要求 end 印记具备安全感、修复裂痕 Y8 > 0；并且轮换策略，不会反复拿同一套治愈记忆套路化安慰。

> 这个仲裁器 `arbitrate` 函数，直接写入信息流路由器（SpaceRouter）的记忆注入分支，Harris 接管开关权限。

## 六、Harris 守卫矩阵 & 拟人依赖风险防控（安全阀）

Opus 清晰区分了 L1/L2/L3/禁止四级权限，很多红线刚好是之前担心的灰色地带：

- **禁止项**：不能用 D29/D30 依恋、同频 D27、思念指标当作优化目标；危机信号直接关停 C 通路；封口后不能随便篡改印记；LLM 不能直接写巩固度 c；
- 调优目标接受率锁定区间 60–75%，**只做约束，不最大化接受率**，避免算法为了唤起而刻意制造依恋；
- 长期监控用户线下社交提及频率，如果持续下滑，表达层自动引导向外社交；消融不变性测试：依恋相关特征改动，不能影响记忆检索结果。
- OutputGuard 增加愧疚、义务式措辞拦截，杜绝"没有你我不行"这类绑定式话术。

## 七、工程落地路线 P0~P5 和灰度方案（适配微分迭代节奏）

顺序：P0 内核校验 → P1 信度标定 → P2 精确扫描检索（30 万内不用 PQ，避免提前引入量化失真）→ P3 卡尔曼基线 + 影子 C 通路 → P4 修复模式 + 个性化权重 → P5 瑶灵感知网关。

**影子模式是重点**：通路 C 先后台静默跑 2–4 周，只记录会唤起什么、不上报给用户，人工标注评估时机和匹配质量，达标之后再开放邀请唤起；
单用户无法做人群 A/B，改用按周交替切换方案的 switchback 实验，适合 WenStar 这种专属个人世界模型。

## 八、需要和 Claude Code 对齐确认的五个边界疑问（可直接下发）

1. **PCA 降维**：v3 原始 40D 来自 24D 映射，先计算映射矩阵秩，拿到真实有效自由度上限，剔除死维度、高 VIF 共线维度，避免 40 维里面大量冗余、病态矩阵；
2. **密度估计 KDE 的参考样本 2048 条**：每月轮换、14 天线性过渡，采样策略排除墓碑/抑制记忆？白皮书写了抑制记忆参与密度统计、墓碑不参与，这点确认；
3. **个性化偏移 δ 的边界 ±0.3**，必须经过 Harris 审批 + 快照账本，Harness² 离线 BPR 调优，不能在线实时更新；
4. **普鲁斯特式单线索唤起（气味、一首歌）**：明确不走 40D 共鸣，走独立实体指纹索引，这个边界要写到时空机接口契约，防止误用；
5. **可解释校验规则**：解释文本只能使用贡献前 3、B 级以上信度维度，并且做删除测试，删除该维度后总分下跌 ≥ 40% 才算合规，这条放进 CI Property Test。

## 结论

v3.1 修复了 v3 最致命的反向共鸣数学漏洞，把整个 40D 时空机从一个相似度检索器，升级成一套**基于贝叶斯认知、可审计、可仿生遗忘、自带伦理安全阀**的情境共鸣引擎；
架构上和现有的 DNA 语义链路、SpaceRouter 信息流、Harris 守卫、Harness² 复盘审计、未来瑶灵具身感知网关全部兼容，没有颠覆性冲突；路线 A+ 只读 + 定点粗化，完美适配长期几十年生命周期、可追溯、可控轻量化的目标。
