# P090 - Claude 任务：群聊「向全员提问 → 全员依次回答」能力

> 背景：生产测试发现——群聊有徐诗雨和罗珍思时，用户问「你们有什么看法/大家都记住了吗」，
> 只有先加入的徐诗雨回答，罗珍思不答。正常应全员先后作答（会议/群聊常识）。
> 豆包读源码确认根因：**系统没有 askAll 能力**——意图分类无此类型、发言人推断永远只返回一人、
> 回复生成单轮单发言。本任务书为 Claude 侧（状态机+输出层），意图识别在 P091（PI）。

## 一、源码现状（豆包核实）

1. `src/m4/household/EntityMeeting.ts:67` `MessageIntentKind` = exit|wake|switch|addParticipant|normal
   —— **无 askAll**；「你们怎么看」被归为 normal，不触发任何调度。
2. `EntityMeeting.ts:572-609` `inferSpeaker()`：①内容提及一人→其接；②LLM 判断最该谁接→**只返回一个**；
   ③默认当前发言人。**无「全员轮答」分支**。
3. `src/webui/chat.ts:1146-1161`：只调一次 inferSpeaker → 至多 dispatch 一次 SPEAK → 生成**一个**回复。
4. `src/m5/group/types.ts:99-121` Action = WAKE|JOIN|SPEAK|LEAVE|RESUME|IDLE；SessionEffect = saveSlot|restoreSlot|
   meetingStarted|meetingEnded|participantJoined|participantLeft|speakerChanged。

## 二、任务分配

### 任务 1：状态机支持「全员发言队列」（P0）

**目标**：GroupSession 支持 askAll 语义——收到「向全员提问」时，把参与者组织成发言队列，
每轮依次切换主发言（SPEAK），全员答完队列清空。

**设计要点（与 PI 的 P091 意图接口对齐）**：
- 新增 Action：`{ type: 'ASK_ALL', now?: number }`（或在 SPEAK 上加队列标记，选更符合
  ADR-013 状态机哲学的方案）
- 队列语义：按参与者加入顺序（participants 数组序）排队，跳过当前发言人；
  每答完一个推进队头；队列空 → 恢复正常（normal 单点回答）
- 状态机纯函数（reduce/diffEffects 零副作用），队列只在 state 上表达；
  副作用（如每次切换打日志/持久化）走既有 onEffect 通道
- **隔离红线**：ASK_ALL 只是「依次换主发言」，每个实体回答时的记忆/口吻/上下文
  仍按各自 UUID 过滤——绝不能因队列机制引入串档。这是业主最高红线。

**验收**（配合 P091 意图识别后联调）：
- 群聊 2 人（徐诗雨+罗珍思），用户问「你们有什么看法」→ 徐诗雨答、罗珍思答，**两人都答**
- 群聊 3 人 → 三人依次答
- 队列答完即停，不无限循环；中途有人被点名 → 尊重点名（切到该人），不冲突
- 开关 WS_GROUP_V2=0 时旧路径行为不变（完整回滚）

### 任务 2：输出层支持「多人依次回答」（P0）

**目标**：一次用户消息在 askAll 场景下触发**多个实体的依次回答**，聊天窗口「谁说话显示谁」。

**设计要点**：
- 在 chat.ts 状态机区域（1146 附近）扩展：detectIntent 返回 askAll 时（P091 实现），
  不单轮生成，而是循环：取队头 → SPEAK → 生成该实体回复 → 下一实体 → 再生成 → …
  直到队列空
- 每个实体回复**独立生成**：用各自身份、各自记忆召回（UUID 过滤）、各自口吻——
  绝不用一个 prompt 让 LLM 同时扮演多人（易串）——**逐人生成**是硬约束
- 输出格式：多人依次回答，界面已按「谁说话显示谁」渲染；后端返回结构需支持
  多段回复（数组或拼接带发言人标记，与前端协议对齐——由你确认现有前端能否直接渲染）
- 回答顺序按队列；若某实体无话可说（诚实不编造原则），可跳过（返回 null 或「嗯」）
  但不能因此让其他实体抢答

**验收**：
- 两人群聊 askAll → 两个独立回复，各自身份正确（口吻/记忆边界可辨）
- 三人群聊 askAll → 三个独立回复
- 回复生成失败/超时 → 不阻塞整体（单实体失败跳过，其余继续）

### 任务 3：回归与隔离验证（P1）

- 点名谁谁回答（switch/wake）行为不变
- 聊到谁的事谁接（inferSpeaker 单点）行为不变
- 群聊加人/减人/散会行为不变
- 人格隔离零串档：徐诗雨不引用罗珍思记忆、罗珍思不引用徐诗雨记忆
- tsc=0、全量测试零新增失败
