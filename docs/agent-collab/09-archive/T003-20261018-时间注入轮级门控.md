# T003：时间注入轮级门控

> 来源：PI 10-18 记忆召回战役（P002）。前四轮已把时间注入改为环境元数据定性
> （7888873，三处注入点成对），但压测轮4仍复发一次报时（问"什么时候开始叫妈妈"
> 答了手机时间）。措辞层已到极限，剩最后一件：**轮级数据门控**。

## 问题本质

时间注入是**轮内最显著的结构化数据**，模型对"什么时候"有强模式匹配。
无论护栏措辞多强（元数据定性/负面禁令/正面替代），只要**素材在场**，
匹配就可能发生。措辞管不住的，**直接不喂**。

## 方案（与 P0-2.1 同款方法论：意图判据 → 数据动作）

在 chat.ts 组装 prompt 时：

1. **判据**（复用现有判据，不新写正则）：
   - 若消息命中「过去时疑问」：含 `什么时候|哪天` 且**不**是当前时间问句
     （当前时间问句判据 = `_lazyTemporalFire` 的修正版正则：几点了/现在几点/今天几号/星期几/现在什么时候）
   - 且 `RECALL_TRIGGER_RE` 命中或消息含回忆语境（可选增强，初版可不加）
2. **动作**：该轮的三处时间注入全部**降级为占位符**：
   `【环境数据·当前时间已隐藏——本轮问的是过去，从记忆里找；记忆里没有就说不记得】`
   （当前时间问句时正常注入——行为不回退）
3. 判定结果作为结构信号传入（类似 isMeetingEntry/isMeetingExit 的传递方式）

## 验收标准

- [ ] 「还记得什么时候开始叫妈的」→ 不出现任何当前时间文本，她从记忆答或如实说不记得
- [ ] 「现在几点了」→ 正常报时（行为不回退，回归测试锁住）
- [ ] 「今天几号」→ 正常报日期
- [ ] 混合问句「是什么时候的事，现在几点」→ 报时（含当下问句即注入，宁可多给不可少给）
- [ ] 守卫测试：判据纯函数 + 三处注入点占位符能力断言
- [ ] tsc=0，全量归因零新增
