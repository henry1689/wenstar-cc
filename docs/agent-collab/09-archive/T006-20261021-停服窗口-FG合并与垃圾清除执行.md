2. FG 实体合并（严格按以下顺序，避开三个坑）：
   a. 搬移 TXS-29 的 1 条边（acquaintance_of）到 TXS-25，按 (source,target,relation) 去重
   b. TXS-25 的 aliases 合并 JSON 数组：["都灵","陈都灵", ...原有别名]

   - ⚠️ **别名必须是 JSON 数组格式**（查找 SQL 是 liases LIKE '%"都灵"%'）

3. memories 垃圾清除（方案B标准）：
   `sql
   DELETE FROM memories 
   WHERE recall_count = 0 
     AND calcium_score < 1 
     AND julianday('now') - julianday(created_at) > 30
     AND id NOT IN (SELECT source_id FROM vault_log WHERE source_id IS NOT NULL)
     AND id NOT IN (SELECT id FROM memories WHERE _ANCHOR = 1)
     AND belong_entity_uuid IS NOT NULL
     AND dialog_group_id NOT IN (SELECT dialog_group_id FROM dialog_groups WHERE block_calcium_score >= 5)
   `
   - 🔴 **硬约束**：所有 IN/NOT IN 子查询 必须加 col IS NOT NULL AND 护栏，避免 SQL 三值逻辑静默丢弃 NULL 行（Claude I010 已踩过此坑）
