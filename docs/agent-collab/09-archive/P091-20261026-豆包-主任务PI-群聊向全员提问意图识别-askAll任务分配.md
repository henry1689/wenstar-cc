# P091 - PI 任务：群聊「向全员提问」意图识别（askAll）

> 背景：生产测试发现——群聊有徐诗雨和罗珍思时，用户问「你们有什么看法/大家都记住了吗」，
> 只有先加入的徐诗雨回答。根因是**系统没有 askAll 能力**。分工：意图识别归你（PI），
> 状态机+输出层归 Claude（P090）。本任务书为 PI 侧。

## 一、源码现状（豆包核实）

1. `src/m4/household/EntityMeeting.ts:67`：
   `MessageIntentKind = 'exit' | 'wake' | 'switch' | 'addParticipant' | 'normal'` —— **无 askAll**。
2. `detectIntent`（EntityMeeting.ts:723-836）目前按序判：exit、addParticipant、switch、
   会晤中@/称呼点名、wake、默认 normal。「你们怎么看」落到 normal，不触发全员调度。
3. `inferSpeaker`（EntityMeeting.ts:572-609）：只返回**一个**发言者或 null（维持当前），无全员轮答。
4. 参照你的 P058（exit 意图覆盖扩大）同套路：**宁窄勿滥**——漏判（多答一轮单点）代价低，
   误判（把普通对话当全员提问）代价高。

## 二、任务分配

### 任务 1：askAll 意图识别（P0）

**目标**：`MessageIntentKind` 新增 `'askAll'`；`detectIntent` 在**群聊（multi）场景**下识别
「向全员提问」句式。

**识别规则（保守，宁窄勿滥）**：
- 触发词（征询性问句 + 复数对象）：「你们/大家/各位/都 + 看法/意见/想法/观点/记住了吗/听懂了吗/
  还有吗/有什么想说的/怎么看/怎么想」等
- 结构判据：必须含**复数对象词**（你们/大家/各位）或**全称量词**（都）且是**疑问句**
  （吗/么/？/怎么看/怎么想/有什么…），两者缺一不触发
- 示例命中：「你们有什么看法」「大家都记住了吗」「各位说说想法」「你们觉得呢」
- 示例不命中：「你有什么看法」（单数→normal）；「你们先聊，我去倒水」（非疑问→normal）；
  「大家都很好」（陈述→normal）；「诗雨你怎么看」（点名→switch，保留）
- 边界：单人会晤（participants=1）不触发（无需全员）；群聊中「点名谁+提问」优先走 switch

**接口**：`MessageIntent` 增加 `kind: 'askAll'`（targets 空或填全体参与者），与 P090 的
Action（ASK_ALL）对接。

### 任务 2：交叉验证（P1，Claude 完成后）

**独立复证**（不依赖 Claude 报告）：
1. **意图层**：askAll 命中/不命中用例各 ≥10 条（含上面示例），检测结果正确率 100%
2. **联调**：群聊 2 人/3 人，用户 askAll → 全员依次回答（每人独立回复，身份正确）
3. **隔离红线**：全员回答零串档——徐诗雨不引用罗珍思记忆、罗珍思不引用徐诗雨记忆
4. **回归**：点名/换人/加减人/散会行为不变；单人会晤 askAll 不触发
5. tsc=0、全量测试零新增失败
