# 【P0 任务】独立开发 SpaceState 时空机核心原型（隔离开发，零耦合主链路）

## 任务边界

✅ 允许做：

1. 新建独立目录 `src/spacestate/`，所有时空机代码全部放在这个目录下，不修改任何现有文件
2. 实现 v3.1 定义的核心数据结构：
   - `DimReading`（v/pi/src 三元组）
   - 79 维扁平印记结构（9 维共享场景层 + 31 维 self + 31 维 user_est + 8 维 dyad 指数）
   - `scene_imprints_v31` SQLite 表（含外键级联删除）
3. 实现核心算法模块：
   - `dimEvidence` 单维对数似然比打分
   - `fuseDim` 多源贝叶斯融合（同源合并 + Birge 冲突惩罚）
   - OU-Kalman 一维状态滤波
   - 分层基线收缩估计
4. 编写属性测试（Property-Based Test），全部通过以下不变量：
   - 未知维度（pi=0）不增加证据分
   - 印记 σ 增大（模糊），期望证据单调不增
   - 偏离均值越远的吻合，证据分越高
   - 宿主墓碑后，任何查询都不返回该印记
5. 用离线历史对话数据跑通最小闭环：文本 → 40D 估计 → 写入印记 → 共鸣查询 → 返回 UUID 列表

## 绝对禁止（红线，Harris 拦截）

1. ❌ 不修改 `src/memsym/` 下任何现有文件
2. ❌ 不修改 `src/spacerouter/` 路由逻辑
3. ❌ 不接入实时对话流，不修改对话输出
4. ❌ 不实现 PQ 索引、不做瑶灵传感器对接（留到 P2/P5）
5. ❌ 不做通路 C / 通路 B 的真实注入，只做离线计算

## 验收标准

1. 所有属性测试 100% 通过，CI 无失败
2. 离线数据集上共鸣检索结果可解释（能输出贡献维度列表）
3. 代码独立目录，和主系统无内部调用
4. 输出执行报告，写入 active 协作区，包含：代码路径、测试覆盖率、离线跑通的样例结果
