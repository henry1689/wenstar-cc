## 一、根因

`.env` 的中文注释是 **UTF-8 字节被当作 GBK 解码后，又以 UTF-8 存回** —— 双重编码错配。

实证：`褰撳墠: DeepSeek` 按 GBK 编码回字节、再按 UTF-8 解码 ⇒ `当前: DeepSeek`（还原成功）。

**但不是所有行都能机械还原**：
- 820 个非 ASCII 字符可 GBK 编码（可还原）；
- **74 个是私用区(PUA)字符**（mojibake 典型产物，`U+E000–U+F8FF`），无标准映射 ⇒ **不可逆**；
- 若整段 `encode('gbk')`，任一 PUA 字符即令整段失败 ⇒ 改为**按字节流分段还原**，PUA 位以 `?` 占位；
- 占位处再按语义补全（如 `切?false` → `切回 false`、`馃敶` → `🔴`、`鈹€` → `──`）。
