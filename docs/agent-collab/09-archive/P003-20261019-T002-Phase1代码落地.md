### ⚠️ 发现一处质量缺口（需下一批修复）

**141 / 688（20.5%）的摘要是兜底文本，不是三层格式。**

根因：`formatSummary()` 在 LLM 输出无法解析为 JSON 时回退为原始文本（保证可检索，但不满足三层格式契约）。
最可能是 `maxTokens=400` 对「JSON + 中文摘要」偏紧导致截断。

**下一批修复建议**（与 meeting_entry 跳过逻辑一并做）：
1. `maxTokens` 400 → 600；
2. JSON 解析失败时**重试一次**（更严格的「只输出 JSON」提示）；
3. 重试仍失败时，把原文包成 `【叙事】…`，保证格式契约至少成立；
4. 待办：`meeting_entry` 直接标 `skipped`（R006 已裁决）。

### 🔴 运维发现：重启后出现两条 webui 进程链

验收中发现 `pm2 restart` 后存在**孤儿进程链**（旧 container → tsx → server），它持有旧内存库并定时落盘，
会覆盖新实例的写入——表现为「日志显示成功、库里仍是 NULL」。
已 `taskkill /T` 清理孤儿链，只保留 pm2 管理的 `36264 → 22668 → 36752`，清理后数据稳定。
与 memory 中「webui 多实例覆盖」是同一类问题，建议后续在重启脚本里加单实例校验。
