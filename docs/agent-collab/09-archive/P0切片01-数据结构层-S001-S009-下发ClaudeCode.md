## 一、你要实现的 9 个条目

### S-001 🔴 79 维布局

LAYOUT 常量正好 79 项，下标与（块，维度）映射如下：

| 下标范围 | 块 | 内容 |
|---|---|---|
| [0..8] | scene 场景 | D32–D40（9 维，全系统共享一份） |
| [9..39] | self | D01–D31（31 维，瑶灵自己） |
| [40..70] | user_est | D01–D31（31 维，对用户的估计） |
| [71..78] | dyad | Y1–Y8（8 个关系指数） |

校验：写一个黄金表单测，逐项断言 LAYOUT[i] 的（块，维度编号）与上表一致。

### S-002 🔴 值域表

**双极维**（值域 [-1,1]）：D01 D02 D03 D05 D06 D07 D09 D11 D14 D15 D31 D32 D34 D36–D40，以及 Y2 Y4 Y7 Y8。
**其余为单极维**（值域 [0,1]）。
越界输入必须被截断并计数（记录截断次数，不抛异常）。

### S-003 🔴 DimReading 结构

```
DimReading = { v: number, pi: number, src: string }
```

- pi=0 时 v 必须被忽略（视为未知）。
- **类型定义里不允许出现 sigma 或 variance 字段**——接口只传精度 π（1/方差），不传方差。
- 所有读取 v 的地方必须先判断 pi > 0。

### S-004 🔴 int8 量化（对称舍入）

```
q(x) = sign(x) · floor(|x| · 127 + 0.5)，截断到 [-127, 127]
```

⚠️ 注意：不用 Math.round（JS 的 Math.round(-63.5)=-63，Python 银行家舍入结果不同）。
反量化：dequantize(q) = q / 127。

### S-005 🔴 精度 uint8 对数编码

```
k = clamp(round(128 + 14.75 · log2(π)), 1, 255)
π = 0 时 k = 0（表示未知）
解码：π = 2^((k − 128) / 14.75)
```

### S-006 🔴 σ 下限与 ICC 精度上限

- σ 下限 0.05，即 π ≤ 400（传入 π > 400 时按 400 截断）。
- ICC 精度上限公式：π_cap = ICC / ((1 − ICC) · τ²)。

### S-007 🔴 NaN/±Infinity 视为未知

任何计算输入出现 NaN 或 ±Infinity，该读数按 pi=0 处理。属性测试：10⁵ 组带 NaN 随机输入，输出里 NaN 数为 0。

### S-008 🔴 主体块 D27 存储精度恒 0

self 块 D27（下标 9+26=35）和 user_est 块 D27（下标 40+26=66）的 prec 写入后必须恒为 0。
（D27 同频只在逻辑视图由 dyad Y1 回填，证据只在 dyad 块计算，不重复计入。）

### S-009 🔴 D39/D40 昼夜相位按本地时间

```
θ = 2π · 本地分钟数 / 1440
存为 (sin θ, cos θ) 两个分量，精度固定 π = 400
```

## 二、黄金算例（你必须跑通的验收数字）

```
G-004  int8 量化
  q(0.5)=64   q(-0.5)=-64   q(0.3)=38   q(1.0)=127   q(-1.2)=-127
  q(0.0039)=0   q(0.00394)=1
  反量化：64 → 0.503937（容差 1e-6）

G-005  精度编码
  π=25    → k=196 → 解码 24.42   （相对误差 ≤2.5%）
  π=400   → k=255 → 解码 390.8
  π=0.002 → k=1   → 解码 0.00256
  π=0     → k=0   → 解码 0（未知）

G-006  ICC 精度上限（τ=0.3）
  ICC=0.5 → 11.111    ICC=0.75 → 33.333    ICC=0.9 → 100.0

G-009  昼夜相位 θ=2π·min/1440
  00:00 → (sin 0, cos 1) = (0, 1)
  06:00 → (1, 0)
  18:00 → (-1, 0)
  21:00 → (-0.707107, 0.707107)
  容差 1e-9；0 值允许 |x| ≤ 1e-12
```

## 三、符号表（本切片用到的）

| 符号 | 代码名 | 单位/值域 | 说明 |
|---|---|---|---|
| v | v | 单极 [0,1]，双极 [-1,1] | 维度值 |
| π | pi | 1/方差，[0,400]，0=未知 | 接口只传 π，禁止出现 sigma/variance 字段 |
| σ | sigma | 值域单位 | 只在公式内部，σ = π^(−1/2) |
| ln / log2 | Math.log / Math.log2 | — | 只有精度编码用 log2，其余全用自然对数 |
