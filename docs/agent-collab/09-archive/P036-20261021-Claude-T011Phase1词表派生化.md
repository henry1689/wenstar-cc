## 二、架构决策（ADR-012 D1）

**原则**：只保留一个 `getRelationLabel(relation, isOutgoing)` 函数，内部从 DEFS 取 label 和 reverse。所有调用方统一走这个函数。

**派生逻辑**：
```typescript
// RelationLabels.ts
export function getRelationLabel(relation: string, isOutgoing: boolean): string {
  const def = RELATION_TYPE_DEFS[relation];
  if (!def) return relation; // fallback
  
  if (isOutgoing) return def.label;
  if (def.reverse === relation) return def.label; // 对称关系
  
  const reverseDef = RELATION_TYPE_DEFS[def.reverse];
  return reverseDef ? reverseDef.label : def.label;
}
```

**向后兼容**：`REVERSE_RELATION`/`ALL_REVERSE`/`SOCIAL_REVERSE`/`SOCIAL_LABEL_CN` 保留为向后兼容别名（内部使用），实际值从 DEFS 派生。
