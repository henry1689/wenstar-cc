- 线索提示 `buildCluePrompt` / `buildClueRecall`；
- 原文/档案锚点规则 `buildDialogArchiveRule` / `buildKnowledgeArchiveRule`。

纯常量 + 纯函数，无运行时副作用、无外部依赖、无循环引用。
