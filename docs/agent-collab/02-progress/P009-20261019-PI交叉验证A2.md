## 四、进程甄别记录（避免误判 I005）

排查中发现一条 `harness-mcp` 树下的 `server.ts` 进程（PID 47944），经核实为**误报**：
- 47944 实为 **harness MCP server**（LISTEN 127.0.0.1:8765，即 Harness flow 端点），exec cwd=`D:\AI文件\harness`
- 其命令行含 `D:\tools\wenstar-cc\node_modules\tsx\...server.ts` 是**复用了 wenstar-cc 的 tsx 二进制路径**，被宽泛 grep `wenstar-cc.*server.ts` 误匹配
- **非 wenstar webui 重复实例**，与 I005 双写无关

**教训**：进程甄别必须按「实际运行的 server.ts 路径 + cwd + 端口持有」判定，不能只 grep 命令行子串（tsx 二进制路径会造成跨服务误匹配）。
