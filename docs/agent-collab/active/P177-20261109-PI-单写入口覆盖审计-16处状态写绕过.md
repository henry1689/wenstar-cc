## 四、收口方案骨架（下一批 Harness 的 S2 素材，本轮不动代码）

1. **网关扩方法**：`MemoryWriteGateway` 增加状态类专用方法（A/B/C 三组对应），**列清单由网关单源维护**（与 writeMemory 同思路）；
2. **豁免白名单**：MigrationManager（启动迁移）与 SELECT 类只读不入；写豁免必须显式登记（防将来 231 处 writeRaw 混淆视听）；

4. **租约约束**：`SQLiteAdapter.ts`、`persistence-stage.ts`、`SleepTimeConsolidator.ts` 均可能与对方窗口/批8 相撞——**执行前逐文件确认 git status 干净**。
