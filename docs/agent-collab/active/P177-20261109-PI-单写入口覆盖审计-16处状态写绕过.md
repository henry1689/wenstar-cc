## 一点五、🔴 数字勘误（2026-11-10，应豆包 P182 缺口①要求核清）

**原「16 处」是 grep 行数口径（含水分），精确核清后：**

| 口径 | 数量 | 构成 |
|---|---|---|
| grep `writeRaw` 且含 `memories` 行 | 16 | = **13 实际绕过** + 2 `knowledge_memories`（关联表，非本体）+ 1 注释行 |
| **实际绕过（收口对象）** | **13** | A 组 **8** + B 组 **2** + C 组 **3** |

- **A 组 8**（原写 7，漏 command-consumer 计入）：`YuyaoMemoryService` 63/106/179/180/200/201/208 共 **7** + `command-consumer.ts:86` **1**；
- **B 组 2**（原写 3，虚高 1）：`SleepTimeConsolidator.ts:321/363`；
- **C 组 3**（原写 4，虚高 1）：`dialog-group-stage.ts:246` / `persistence-stage.ts:451` / `yaoling-sensation-pipeline.ts:294` 各 1；
- **D 组 = `maintenance.ts:625` 注释行，非实际绕过，剔除**：原文是「当前 runGC **仅记录告警**。如需激活，将 FusionStorageAdapter 传入 injectDeps 并在 runGC 中调用 writeRaw('DELETE FROM memories ...')」——**runGC 的 DELETE 未激活**；`maintenance.ts:414/498` 两处实际 writeRaw 为 `UPDATE conversations`（非 memories，已核）。
- 另核：`KnowledgeContextBuilder.ts:380` / `KnowledgeEngine.ts:1169` 为 `knowledge_memories` 关联表写，按口径不入清单。

**结论：收口清单以本勘误为准 = 13 处（A8/B2/C3）**；下文 §二表格的 7/3/4/1 分组数字作废，以本节为准。CC 对照去重请用 13 处口径。
