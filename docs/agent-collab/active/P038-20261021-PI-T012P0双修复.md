# P038 · T012 PI 侧进展（P0 双修复）

## ✅ P0-5 多人会晤唤醒失败（提交 `80d64bc`）

**Phase A 摸底**：10 个多人唤醒用例仅 1 过（纯主名版）。
**Phase B 根因**（疑点 B/C/D/E）：多人检测 4 个正则（duMatch/multiMatch/meetingMatch/andMatch）均用**主名裸子串 `.includes(主名)`** 且要求**集合动词在名字前**：
- **别名失效**：「找**诗雨**和阿珍」中"诗雨"是别名（主名徐诗雨），裸子串匹配不到 → 多人退化单人（实测 `[徐诗雨]`）
- **把字句/无分隔/多语序失效**：「把X和Y叫过来」动词在名后、「徐诗雨阿珍过来」无分隔 → 漏召/null

**Phase C 修复**：替换 4 个脆弱正则为「别名归一 + 收集全部提及实体 + 集合线索」鲁棒检测（与动词位置解耦）：
- `_normalizeAliases`：别名→主名（长别名优先防重叠）
- 收集归一消息中全部已知实体提及，≥2 + 集合线索（过来/都来/一起/开会/聊 或 祈使动词+来）
- 疑问句守卫（末尾吗/呢/？且无祈使动词）防「X和Y都来了吗」误入会晤

**验证**：复现探针 **13/13**（10 多人 + 3 反例无误判）· 新回归 `meeting-multi-wake` 8/8 · household/chat/retrieval **38 文件全绿**
