## 一、存量红测试 A：`keywordRecallMemories` 参数数断言已过时

- 文件：`src/governance/police/__tests__/memory-fragmentation.test.ts:118`
- 实测：`expected 3 to be 2`
- 根因：实现侧（`meeting-recall.ts`）P0-1 收编时给关键词路加了**时间窗**第三个参数
  （`[entityUuid, days, %kw%]`，SQL 也相应多一个 `?`），该测试仍按旧口径断言 `params.length === 2`。
  同一用例内的「占位符数 == 参数数」断言是**通过**的（3===3），只有末尾这行写死的 2 是旧值。
- 影响：纯测试债，不影响生产行为；但它让 `src/governance/police` 套件长期带红，
  任何人跑全量回归都会被误导（我这次就一度以为是自己改坏的）。
- 建议：把 118 行改为 `expect(capturedParams.length).toBe(3); // [uuid, days, %kw%]`，
  或改成 `expect(capturedParams.length).toBe(placeholders)` 以免再次写死。

## 三、T003 时间坐标标签使三处正则静默失效（**两处独立复核一致**）

2026-10-18 T003 给所有注入标签加了时间坐标后缀（`【X的记忆·10-20】`），但三处依赖
「标签形如 `【X的记忆】`」的正则没有同步，全部变成 **fail-open（静默失效，无告警）**：

| # | 位置 | 现象 | 后果 |
|---|---|---|---|
| 1 | `governance/police/UUIDPoliceFilter.ts:256` `screenContext` | 正则要求替代项**紧邻** `】`，`·10-20` 使 `【X的记忆·10-20】` 不再匹配 | 会晤「注入边界兜底闸门」对**几乎所有**记忆片段空转（`filteredCount` 恒 0）。下层查询已按 UUID 收敛，故无泄漏面，但闸门的兜底价值归零 |
| 2 | `m4/MemoryInjector.ts` 的 `kind` 判定 `/^(…\|【.+的记忆】)/` | 同上，`记忆】` 后跟 `·10-20` ⇒ 不匹配 | 本应归 `context`（豁免相关性精筛与条数上限）的记忆被判 `sand`，照常受精筛与条数上限约束 |
| 3 | `m4/MemoryInjector.ts:158` 优先级 `frag.includes('记忆')` | 高钙对话组标签 `【X的对话组·高钙·10-20】` **不含「记忆」二字** | 优先级 0.85→0.60（低于金库 0.70），且**随正文是否恰好含「记忆」一词抖动** |

**任务 F 的处置**：第 3 项已就地收敛——组标签改为含「记忆」（`【X的对话组记忆·高钙·MM-DD】`），
优先级固定 0.85 且不再随正文抖动，并有测试 `recall-quota.test.ts` 锁定该耦合。
第 1、2 项**未动**（不在本次范围，且改它们要动 `UUIDPoliceFilter.ts` / `MemoryInjector.ts` 两个非豁免文件）。

**建议修法（2.4）**：三处正则统一容忍时间后缀——`】` → `(?:·\d{4}-\d{2}-\d{2}|·\d{2}-\d{2})?】`。
根因是「标签格式变了，消费方各自持有一份正则」，更彻底的做法是把标签的**拼装与解析**收敛到单源
（任务 F 已在 `recall-quota.ts` 的 `TAG` + `tagOf` 上示范了这个形态）。

## 四、补充发现（2026-10-20 抓 I007 日志时）：注入边界闸门的**日志本身在误导**

生产日志出现过：
```
[UUIDPolice] 注入边界闸门: 39→64 条（剔除他人实体片段）
```
数字**变多了**。原因：`screenContext` 是按 `\n` 切分后再拼回，而**单个 fragment 可能含多行**，
于是这一行打印的其实是「片段数 → 行数」，不是「过滤前 → 过滤后」。
⇒ 过滤到底剔除了什么，从这行日志**完全看不出来**。

叠加 §三第 1 项（时间坐标标签让正则失配）⇒ 这道闸门目前**既空转又谎报**。
建议修法（2.4，与 §三 一起）：
- 比较口径改为「过滤前后的**片段**数」，或在 `screenContext` 返回值里带上真实剔除计数；
- 标签正则容忍时间后缀 `】` → `(?:·\d{4}-\d{2}-\d{2}|·\d{2}-\d{2})?】`。
