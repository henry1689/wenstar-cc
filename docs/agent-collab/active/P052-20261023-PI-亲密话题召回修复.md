# P052 · 亲密话题召回修复（A+C）

## 根因诊断（用户实测：徐诗韵问"亲热的事"说没有）
**数据没丢**：徐诗韵有 15 条亲密记忆 + 11 条亲密对话 + 20 个含亲密摘要的组，未被排除（is_test=0/default），**钙分与日常相当**（亲密0.625 vs 全部0.671）。

**真因是召回捞不到**：
- 召回靠**关键词字面匹配**——含"亲热"二字的组摘要**只1个**（含"亲密"20、"暧昧"16），问"亲热"字面命中面极窄
- 亲密记忆多为钙<1，钙分优先通道不捞
- → 那段记忆没被召回进上下文 → 她如实说"不记得"（诚实规则生效，非回避）

## 修复（A+C，业主批准）
`meeting-recall.ts`：
- `INTIMATE_TOPIC_RE`（亲密话题检测）+ `INTIMATE_KEYWORDS`（亲密词集）
- `extractTopicKeywords` 命中亲密话题时**返回整组亲密词**——"亲热"类查询能匹配含"亲密/暧昧/床上/上床/抚摸…"的组（**治本：话题感知召回** + **扩词**）
- 日常查询不受影响（走原滑窗抽词）

## 验证
- tsc=0（除 meeting-prop-points.test.ts 预存在错误）
- 实测："亲热的事"→返15个亲密词；"亲密"→同；日常"讲题"→仍返日常词
- m4/retrieval + webui/chat **288 测试全绿**
