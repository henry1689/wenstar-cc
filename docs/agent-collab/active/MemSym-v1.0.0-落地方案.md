## 二、三处现实校准（与原架构图的差异及理由）

### 校准①：命名空间门降级为预留钩子

**原假设**：SpaceRouter 做 REAL_HISTORY / FICTION_LORE 域分流

**现实**：
- `src/m5/space/` 是**场景域**路由（会晤/独处/耳语），不是真实/虚构域
- REAL_HISTORY / FICTION_LORE 代码不存在（roleplay V5.0 未复活）

**校准方案**：
- v1.0 全域皆 REAL_HISTORY
- 通路分发器直接挂检索层入口
- 域门做成接口占位，V5.0 roleplay 复活时无缝接上
- **理由**：不建在不存在的基础设施上

> 📌 **业主补强（2026-11-01）**：
> **v1.0 "全域 REAL_HISTORY" 是临时运行模式，不是永久架构**。
> 写清楚这是阶段性妥协，避免以后维护时，有人把"没有 FICTION_LORE 分流"当成设计常态，忘记预留钩子的目的。
> 同时补充一条边界注释：**所有角色扮演、虚构叙事隔离能力推迟到域基础设施就绪之后启用**。

---

### 校准②：masterProfile Legacy 分两期收编

**原假设**：一次性切到 PickedElement 标准接口

**现实**：
- masterProfile 涉及 PFC / M6 三模块
- 一次动三模块是本次会话反复验证过的雷区

**校准方案**：
- 批γ：先并行运行（旧 masterProfile + 新 PickedElement）
- 批ε：灰度对比后裁决退役
- **理由**：避免一次动 PFC/M6 三模块

---

### 校准③：宪法摘要落 governance/

**原假设**：太虚境宪法是宪法载体

**现实**：
- `governance/` 目录就是事实上的宪法级文档集（户籍法/40D法令/管控章程）
- 引用的《太虚境宪法》文件在常规路径未定位

**校准方案**：
- MemSym宪法摘要落 `governance/`
- 太虚境宪法找到后加交叉引用
- AGENTS 索引登记

## 五、核心信条（宪法摘要草案）

> 以下为宪法摘要核心内容，待批α 正式定稿

1. **记忆不是原始快照**，是经过权重筛选、情绪加权、离线巩固之后的要素子集
2. **合法表达** = 在封闭、审计可溯源要素池内重组、润色、渲染感受；**编造** = 引入要素池之外的事实要素冒充历史事实
3. **记忆有两种服务模式**：应答回溯问询（通路A）、滋养当下陪伴（通路B）；二者边界由语义主旨判定
4. **默契是自生长、可衰减、有上限的有机过程**：反复珍视的特质权重自然抬升，长期闲置的记忆要素自然淡化
5. **所有记忆取用、钙化变更、元素萃取都必须可溯源、可审计、可回滚**
6. **命名空间隔离不变**：MemSym 仅作用于 REAL_HISTORY 真实历史域；FICTION_LORE 虚拟叙事域走独立叙事规范
