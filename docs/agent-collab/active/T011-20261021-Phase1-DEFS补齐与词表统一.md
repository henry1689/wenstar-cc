落实 FG 结构规范 V1.0 第一步：关系类型单一真源。补齐 RELATION_TYPE_DEFS 缺失的 32 项，建立启动断言，将 5 套分裂词表改为从 DEFS 派生。

## 任务内容

### 1. RELATION_TYPE_DEFS 补齐（Claude 主导）

#### A-1 必须补定义（28 项）
- elder_sister_of / younger_sister_of / elder_brother_of / younger_brother_of
- niece_of / nephew_of / grandparent_of / sister_of / brother_of
- lover_of / lives_in / residence_of / close_to / has_appearance / has_feature
- patient_of / org_of / employer_of / employee_of / consultant_of / server_of
- vendor_of / investor_of / supplier_of / competitor_of / stranger_of / fellow_of / operated_by

#### A-2 补齐缺失反向目标（6 项）
- step_child_of / child_in_law_of / fan_of / org_of / server_of / grandparent_of

#### A-3 迁移/删除（3 项）
- 其他（DB 7条）-> 迁移为 acquaintance_of 或人工裁决后删
- has_feature -> 并入 has_appearance 或 selfProfile 字段
- sister_of/brother_of -> 归并到 sibling_of（方向信息由 edges 自带）

每项必须包含：category / label（中文）/ reverse（反向关系名）

### 2. 启动断言（PI 主导）

在 server.ts 启动路径增加 3 项断言：
1. 写入白名单 subset of DEFS（违反 fail-fast）
2. DEFS 中每个 reverse 目标 in DEFS（违反 fail-fast）
3. 每个 DEFS 类型有中文 label（违反 fail-fast）

断言失败时：输出具体违规类型列表，阻止服务启动（不是警告）。
