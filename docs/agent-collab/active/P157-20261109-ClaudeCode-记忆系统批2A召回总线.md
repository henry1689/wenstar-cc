## 一、交付物

### 1. 新模块 `src/m4/recall/recall-bus.ts`

- `RecallMode = casual | standard | deep | proactive`；
- `RecallTier = sand | gold | diamond | group | knowledge | long_text | work | other`；
- `classifyFragmentTier`：按注入标签分层；`【用户状态】/【系统…/【引擎…` 归 `other` 直通；
- `dedupeCandidates`：去标签/括号/后缀 + 空白归一，同文留分高者；
- `applyTierFloors`：砂金/金库/黑钻/对话组各自最小名额，剩余按分补足；`other` 不占记忆名额、不被 total 截断；某层不足时 `shortfalls` 如实记录；
- `applyGate`：单一五级闸门挂载，映射 `calcium_score/effective_strength/created_at/is_landmark`，按闸门 `effective_strength` 排序（G2/G4/G5 降权真正参与）；
- `runRecallBus`：去重 → 闸门 → 层保底 → 截断，输出 `selected/dropped/gateStats/tiers/shortfalls`；
- `applyRecallFeedback`：白名单表（`memories`/`black_diamond`/`knowledge_base`）回写 `recall_count` + `last_recalled_at/updated_at`，同轮同 id 只记一次。

  - `gate.enabled` / `feedback.enabled`
- `src/config/retrieval-fusion-config.ts`：新增 `RecallBusConfig` 接口、默认值、逐层深合并。

### 3. `src/webui/chat/retrieval-stage.ts`

- **casual 不再早退**：保留 `collectCasualFloorMemories`，新增一次小预算 `startFoundationRouteTask`（黑钻/金库/知识/对话组），合并后过 `runRecallBus(mode='casual')`，并对 Foundation 命中 `applyRecallFeedback`。
- **普通出口**：配额之后过 `runRecallBus(standard|deep)`，用 selected 重写 `memoryFragments`；统一回写本轮收集的 V13/V11/Foundation 锚点。
- **会晤出口**：配额之后过 `runRecallBus(mode='deep')`。
- **V14 下线（D1）**：普通 `WS_SEARCH_V14` 与会晤 `WS_V2_REPLACE_LEGACY` 均改为 `process.env.WS_SEARCH_V14 === 'true'`，默认 false；应急回滚一个环境变量。
- **反馈单一实现**：删除 V13/V11 内联 `UPDATE black_diamond ... recall_count`，改为 `_recallFeedbackRefs` 收集 + 出口 `applyRecallFeedback`。

### 4. `src/m4/retrieval/adapters/BlackDiamondAdapter.ts`

- 整句 LIKE → `buildDiamondShards`（标点切词 + 重叠 CJK 2-gram，最多 12 片）+ 多片 OR LIKE；

- 保留 UUIDPoliceFilter deny-by-default 与 backref。
