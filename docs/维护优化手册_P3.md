- 每次只拆一个模块，编译+测试后再拆下一个
- 新模块与旧文件并行运行一段时间，验证无回归后删除旧代码
- 拆出时不改变行为逻辑，纯搬迁

## P3-5: 术语统一

| 术语 | 别名 / 易混淆 | 标准用法 |
|:---|:---|:---|
| **实体** | entity, person, character, 角色 | `entity` — 数据概念；`角色` — 扮演概念 |
| **UUID** | TXS-ID, uuid, belong_entity_uuid | `TXS-ID` (格式) / `belong_entity_uuid` (列名) |
| **记忆** | memory, 金库, 砂金, 黑钻 | `memories` (表) / `金库` (语义层) / `黑钻` (black_diamond) |
| **会晤** | entity_meeting, meeting, 实体会话 | `entity_meeting` (ChatMode kind) |
| **角色扮演** | roleplay, rp, 扮演 | `roleplay` (ChatMode kind) |
| **人格** | persona, personality, M6, 自我模型 | `M6` (模块) / `persona` (PromptBlock type) / `自我模型` (概念) |
| **钙化** | calcium, calcium_score, calcium_level | `calcium_score` (0-10 连续值) / `calcium_level` (0-3 离散值) |
| **门控** | gate, guard, policy, PFC | `PFC` (前额叶模块) / `ChatPolicy` (会话权限) / `guard` (PromptBlock safety) |
| **编排** | orchestrate, pipeline, assemble | `CognitivePipeline` (M4→M5) / `PromptAssembler` (块组装) / `retrieval-stage` (检索) |
