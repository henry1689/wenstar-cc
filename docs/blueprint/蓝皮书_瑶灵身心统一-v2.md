## 一、总纲（业主立法级，四环）

> **肉身全身都是存感神经——40D 必须被全面理解、诠释、表达，并持续反馈给天权。**

```
理解  →  诠释  →  表达  →  反馈
 ↑                      ↓
 └──── 天权（大脑中枢） ←─┘
```

| 环 | 机制 | 实现位置 |
|---|---|---|
| **理解** | SENSATION_MAP：**D1-D40 全通道中文映射**（肉身 8 + 内在精神 12 + 时空环境 12 + 亲密纹理 8），一个通道不漏 | 模块常量表 |
| **诠释** | `deriveSensation`：全通道扫描，≥0.55 阈值命中，按强度降序取 top5，分组呈现（body/drive/bond/world/mind） | 纯函数 |
| **表达** | 【此刻的身体与渴望】注入块 → AI 实体以角色口吻**自然流露**（不念清单、不报数值） | EntityContextBuilder |
| **反馈** | 三层主动反馈（下表）回传天权 → 更新身体缓存 → 下一轮表达立即体现 | 模块 + 总线 |

## 二、主动反馈系统（三层）

| 层 | 触发 | 语义 |
|---|---|---|
| **① 对话驱动** | 每轮 M3 情绪态 → `tianquan_snapshot` → 瑶灵 40 通道 → 回包 | 说话时身体跟着动 |
| **② 周期滋养** | `startBodyTick` 每 5 分钟**主动**向瑶灵要快照（沿用最后情绪基调） | **身体持续存在**——不等对话，激素水平一直在 |
| **③ 突变即推** | 回包时检测 max&#124;Δ&#124;≥0.25 → 缓存立刷 + `[YaolingSensation] 身体跃变` 可观测 | 渴望飙升/体感突变**即刻进入表达** |

## 三、分层铁律（不变式）

1. **写入只补 D01-D08**（肉身八维，不覆盖 M3 语义维与瑶光已供值）——40 维全量**只用于诠释与表达**；
2. **量纲合规**：不改 40D 维度定义与扇区（《40D 量纲统一法令》）；
3. **原典零改动**：瑶灵侧接收闭环/流水线/推送为既有建成物；
4. **故障全静默**：任何失败绝不阻塞 chat 主链（fire-and-forget）；
5. **注入降级安全**：无身体状态/陈旧 >30min → 注入块整段跳过。
