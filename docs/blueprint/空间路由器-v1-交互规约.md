## 0. 本文件解决什么问题

白皮书只定义「`focus` 是发言权」，**没有定义上层指令如何驱动 focus、如何驱动席位增减**。
若不写死这层契约，写意图解析层的人会各自脑补一套规则，与设计意图分叉，且分叉很难在测试里暴露。

**本文件只写**：识别到哪一类意图 → 向路由器提交哪一类 flow。
**本文件不写**：NLP 怎么解析、提示词怎么写、UI 怎么展示。

## 1. 两条通道（不得混用）

| 通道 | flow 形态 | 语义 | 谁用 |
|:---|:---|:---|:---|
| **人类指令通道** | `{ kind:'command', raw, ts }` | `raw` 是**自然语言文本**，由内核 `parseCommand()` 解析 | 业主说的话 |
| **机器指令通道** | `{ kind:'internal_seat_op', op:'enter'\|'leave', targetUuid, ts }` | 直接给 **UUID**，**不经 `parseCommand`** | 适配器自动同步席位 |

🔴 **严禁把 UUID 拼进 `command.raw`**（如 `"${uuid}过来"`）。这依赖「UUID 恰好不含 `过来/走了/留下` 等命令关键词」的脆弱假设——命令正则一旦放宽就会误解析。两条通道在 `route()` 顶层分流，互不污染。

🔴 **`command` 通道的 `raw` 是业务文本，不是机器协议**。解析失败不是异常，是正常反馈（见 §5）。

## 2. 指令 → 变更 映射表

### 2.1 已实现（内核 `parseCommand()` 现有能力）

| # | 意图 | 触发形态（正则原文） | 路由变更 | 事件 |
|:--:|:---|:---|:---|:---|
| C1 | **入场** | `^@?\s*(.+?)\s*(?:进来\|过来\|来一趟\|来一下\|来聊聊\|来吧)\s*$` | 不在场则该席位**开一段新任期** `enteredAt = 事件 ts`；已是 participant 则发令牌 | `enter` |
| C2 | **旁听入场** | `^@?\s*(.+?)\s*(?:进来旁听\|来旁听)\s*$` | 入座但 `kind='auditor'`，**永远拿不到发言令牌** | `enter`（`asAuditor:true`） |
| C3 | **离场** | `^@?\s*(.+?)\s*(?:先走\|走吧\|走了\|回去\|离开\|去忙\|出去)\s*(?:了\|吧)?\s*$` | 给该席位**开放中的任期**打上 `leftAt = 事件 ts` | `leave` |
| C4 | **只留一人** | `^@?\s*(.+?)\s*留下\s*$` | 目标保留，**所有其他在场席位**离场；保留者若是 participant 则发令牌 | `leave × N`（`reason:'keep_only'`） |
| C5 | **清场** | `^(?:所有人\|大家\|你们)\s*(?:都)?\s*(?:离场\|出去\|散了吧\|先走)\s*$` | 所有在场席位离场 | `leave × N`（`reason:'clear_all'`） |
| C6 | **点名发言** | **句首指名**（如「诗雨，你说说」） | `address = seat(她)`；**若她不在场则自动入场**；`focus = 她` | 随该轮 `say` 记录 `address` |

**C6 的三条推论**（`R1/R2`，易被写错）：

1. **点名即入场**——叫不在场的人，她会被自动拉进来并开一段任期，不需要先说"进来"；
2. **点名即指向**——该轮的 `address` 是 `seat(她)`，而不是 `room`；她自己这一轮会看到 `addressed` 命中，从而知道「这话是给我的」；
3. **点名即发言权**——`focus` 立即转到她身上。

### 2.2 已建模、尚未接线（白皮书 §5 的演进项）

| # | 意图 | 期望变更 | 当前状态 |
|:--:|:---|:---|:---|
| C7 | **耳语**：「XX，跟你单独说」 | `audience = { kind:'seat', uuid }`；其余在场席位只看到 `publicMeta` | ❌ 内核有 `whisper` 事件类型与 audience 判定并有测试，但**上层从未产生该类事件**（实机 `audience` 恒为 `room`）；无解析入口 |
| C8 | **全员问询**：「大家都清楚了吗？」 | `audience = room`；`focus` **轮询调度**到下一个在场 participant | ❌ 未实现。当前未被指名时 `focus` **保持不变**（`focus = focusOrNull(...)`），不轮询、不转移 |

⚠️ **写意图解析层的人必读**：C7 / C8 是**设计意图**，不是现有能力。若上层直接假定它们可用，会产生"看起来在工作、实际什么都没变"的静默失效（`audience` 永远是 room，`focus` 永远不会轮转）。

### 2.3 边界与反例

- **「走」单字不触发离场**——词表刻意为 `先走|走吧|走了|回去|离开|去忙|出去`，避免「诗雨走去哪」被误判。若要扩充，必须同时补反例测试。
- **解析失败必须可见**——`invalid` 会产出 `system` 事件 `command_invalid` 与告警 `command_invalid: <reason>`，不得静默忽略（见 §5）。
- **目标不存在**——产出 `command_target_not_found` 告警，**不创建席位**（内核不查 FG，户籍未知即失败）。

## 3. 业主特权与权限边界

### 3.1 特权集合

业主是空间的**所有者**，拥有**席位变更操作权限**：

| 能力 | 说明 |
|:---|:---|
| 增删席位 | 可叫任何人入场 / 离场（C1–C5） |
| 指定发言权 | 可点名让某人接话（C6） |
| 查看全空间 | 可读取全空间快照与审计日志（不受 `canPerceive` 限制） |

### 3.2 三条不冲突的澄清

1. **特权是"操作权限"，不是"常驻席位"**——业主**不是**一个席位，不进 `seats[]`，不占任期，永远听得见全部（业主视角不做过滤）。
2. **业主可以叫自己独处**——C5 清场后空间为空 = 业主独自说话、无人应答。这与"所有者特权"不矛盾：**有权限叫人来 ≠ 必须有人在场**。
3. **其他角色不能改席位**——目前内核的 `command` flow **没有 actor 字段**，不区分指令来源；因此**权限校验必须放在上层意图解析层**（只有业主输入才翻译成 `command`，角色产出只能翻译成 `agent_say`）。

> ⚠️ 第 3 条是当前实现的**已知缺口**：内核不自证身份，依赖上层守规矩。若将来出现"角色能自我入场"的行为，根因必然在此。

## 4. 审计与快照字段

路由器的可审计性来自"纯函数 + 事件流"，但**字段口径必须固定**，否则后续日志模块各写各的。

### 4.1 快照（`exportSnapshot()`）必含

| 字段 | 含义 |
|:---|:---|
| `spaceId` | 空间标识 |
| `ingestedIndex` | 已摄入历史下标（增量幂等锚点） |
| `lastTs` | 最后事件时间戳（乱序检测基线） |
| `seats[].uuid / displayName / kind` | 席位身份 |
| `seats[].periods[].enteredAt / leftAt` | **任期全量**（不可裁剪——裁剪即失去可复现性） |
| `eventCount` | 事件条数 |
| `diagnostics[]` | 诊断缓冲 |

### 4.2 审计日志应记录的事件类型

| 事件 | 关键字段 | 保留要求 |
|:---|:---|:---|
| 席位增减 | `kind(enter/leave)`、`actorUuid`、`ts`、`reason(keep_only/clear_all)` | 永久 |
| 发言权转移 | 转移前后 `focusUuid`、触发源（点名 / 离场回落 / 保持） | 永久 |
| 听觉范围变更 | `audience`（`room` / `seat:uuid`） | 永久 |
| 指向变更 | `address` | 永久 |
| 时序异常 | `ts_out_of_order`、前后 ts | 永久（可诊断） |
| 解析失败 | `command_invalid` / `command_target_not_found` | 永久（可诊断） |

**判据**：任何一条能改变"谁听得见 / 谁接话"的动作，都必须在审计里留下前后态。只记"发生了什么"不记"之前是什么"的日志，无法复现。

## 5. 失败语义（与白皮书 §2.3 呼应）

| 情形 | 语义 | 是否影响状态推进 |
|:---|:---|:---|
| 命令解析失败 | 产 `command_invalid` 告警 + `system` 事件 | 否，状态不变 |
| 目标席位不存在 | 产 `command_target_not_found` 告警 | 否，**不创建席位** |
| 历史时间戳缺失 | 退化单调递增，产 `history_ts_missing:index=N` 诊断 | 是（按退化值推进） |
| 会晤起点锚点损坏 | **退化为 0（可见全量）** | 是 |
| 事件时间戳回落 | 产 `ts_out_of_order`，**照给定 ts 计算** | 是（不纠错） |
| 归属未知的 assistant 轮 | 产 `history_assistant_unowned:index=N`，**不猜归属** | 否，该轮不进事件流 |
| 任期不变量破坏 | **抛错**（`exportSnapshot()`） | — 宁可炸，不静默污染 |
