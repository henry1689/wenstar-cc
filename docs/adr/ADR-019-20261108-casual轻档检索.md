# ADR-019 · casual 轻档检索（快路径从「开关」改为「档位」）

- **日期**：2026-11-08
- **状态**：已采纳
- **相关**：ADR-018、`docs/LEDGER.md`、MemSym 宪法信条 7（主动模式义务）
- **代码**：`src/m4/retrieval/casual-floor.ts`、`src/webui/chat/retrieval-stage.ts`

---

## 1. 决策

把「闲聊快路径」从**二值开关**（casual ⇒ 零检索）改为**档位**：

| 档位 | 触发（`MemoryGate.decideMode`） | 检索内容 | 明确不做 |
|:---|:---|:---|:---|
| **轻档 floor** | `casual` 且非会晤 | 本地单次 `findByEmotionalSimilarity`（`balanced`，≤3 条，阈值 emotional>0.3 ∥ calcium>0.3，排除当前分支）+ 本轮近期对话 | v11 / v2 / Foundation / LLM 重排 / 实体扩展 / 查询分解 |
| **全档 full** | 回忆 / 知识 / 会晤 / 其它 | 现状全链路 | — |

轻档契约收敛在 `collectCasualFloorMemories()`：**单次调用、阈值收口、永不抛出**（失败=零记忆）。
片段格式与全档 fallback 同源（「用户曾提到」+「不记得就说不太记得了」），不出现第二种提示形态。

## 2. 为什么这样设计（追溯依据）

**事实（2026-11-08 离线重放，玉瑶私聊 927 条真实消息）**：

- `decideMode` 判 `casual` **97.7%**（906/927）；`memory_recall` 11、`knowledge_query` 10；
- casual 中带指代词的 129 条（14.2%）——它们依赖上下文，却拿不到任何记忆。

**冲突**：MemSym 宪法信条 7 ——「**主动**：根据场景主动调用回忆和过去元素丰富话题、增进感情，**义务非可选**」。
零检索实现使玉瑶只有在用户消息命中「回忆/知识」标记词时才可能记得事，其余 97.7% 一律仅凭当前上下文作答。
这不是业主批准的口径（业主批准的是「闲聊可跳过**完整知识检索**」），属于实现把「重档」和「轻档」一起砍掉。

**为什么不是回滚**：回滚会恢复全量 v11/Foundation（首字 +0.4~0.7s），且同样不符合档位理念。
**为什么不是打补丁**：不是「在 casual 分支里塞一行检索」，而是定义**档位契约**并抽成独立模块，
后续新增档位（如「深档」）只改契约与模块，不再改动 `runRetrieval` 的分支。

## 3. 备选方案与为何放弃

| 方案 | 做法 | 放弃原因 |
|:---|:---|:---|
| A. 保持零检索 | 登记为对宪法义务的豁免 | 与 MemSym 宪法直接冲突，且实测 14% 闲聊有指代依赖 |
| B. 回滚快路径 | revert `eb28b76` | 恢复重型链路全部成本，违背档位理念 |
| **C. 档位化（采纳）** | casual = 本地轻档，全档不变 | 保留大部分延迟收益，恢复主动回忆 |
| D. 用 v2/Foundation 做轻量召回 | 调远端/多源但限条数 | 成本仍在网络与多源编排，不符合「闲聊要快」 |

## 4. 影响范围与回滚

**文件**：新增 `src/m4/retrieval/casual-floor.ts` 与测试；`retrieval-stage.ts` 的 casual 分支改为调用；
新增本 ADR。

**不受影响**：v11/v2/Foundation 全档链路、MemoryGate 判定、chat.ts、会晤检索、数据与持久化格式。

**成本与预算**：轻档为一次本地 SQLite 检索（带缓存），实测个位数毫秒；注入 ≤3 条、每条 ≤60 字，
新增 prompt 约 ≤200 字，不改变 22 段注入顺序。

**回滚**：删除 `casual-floor.ts` + 把 casual 分支还原为返回空数组（即 2026-11-07 行为）；无数据变更。

## 5. 后续出问题先看这里

1. **闲聊变慢** → 看日志 `[Latency] fast_path=1 ... tier=floor floor_mem=N floor_ms=X`；
   若 `floor_ms` 明显变大，先查 `findByEmotionalSimilarity` 的缓存是否失效。
2. **闲聊反复提同一件旧事** → 轻档阈值过低或 limit 过大；调 `CASUAL_FLOOR_*` 常量，不要改调用点。
3. **闲聊引用「刚说的这句」** → 检查 `branchId` 是否传入（必须排除当前分支）。
4. **新增档位** → 只在档位契约与 `casual-floor` 模块内扩展；**禁止**再在 `runRetrieval` 里加 if 分支。
