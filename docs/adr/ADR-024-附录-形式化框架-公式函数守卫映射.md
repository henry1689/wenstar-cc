## 一、统一状态空间（v2 拆两对象）

**情景（不可变，只衰减/休眠，永不失效）**：

$$m_{epi}=\big(x,\ \mathbf e,\ \mathbf p,\ t_{tx},\ s,\ n,\ \tau_{last},\ \sigma_{st},\ \mathbf c\big)$$

**事实（带键与有效期，有版本，可失效）**：

$$f=\big(val,\ key,\ [t_v^s,t_v^e),\ t_{tx},\ ver,\ derived\_from\big)$$

| 符号 | 含义 | 现有字段映射 | 状态 |
|---|---|---|---|
| $x$ | 原文（不可变） | `raw_input` | ✅ |
| $\mathbf e$ | dense 向量 + `model@ver` | 新增（M3 影子） | 🆕 |
| $\mathbf p$ | 40D 感知向量 | `perception_40d` | ✅ |
| $key$ | 语义键（**声明基数**：存殁/住址=单值互斥；爱好/朋友=多值共存） | 新增（M4） | 🆕 |
| $[t_v^s,t_v^e)$ | 事件有效时间，**带精度**；解析失败回退 $t_{tx}$ 并打 `v_inferred` | 新增（修正2） | 🆕 |
| $t_{tx}$ | 系统获知时间 | `created_at` + 新 `invalidated_at` | ✅/🆕 |
| $s,n,\tau_{last}$ | 强度/召回数/上次召回 | `effective_strength`/`recall_count`/`last_recalled_at` | ✅ |
| $\sigma_{st}$ | 生命周期（转移表见 §二） | `lifecycle_state` 扩态 | ✅扩展 |
| $\mathbf c\in[0,1]^5$ | 多标签类型（**仅加权不过滤**） | `mem_class` | 🆕 |
| $derived\_from$ | 情景→事实指向 | `dna_root_id` + 摘要来源关系 | ✅/🆕 |

**设计依据**：被失效的是**事实**，不是**情景**——"外公健康"（事实）可失效，"去世前一年那轮对话"（情景）永远真实。AsOf 语义因此干净，"历史对话仍可检出"不再依赖时间过滤技巧。

## 二、生命周期状态机（转移表 + 吸收态 + 闭包）

$$\sigma_{st}\in\{\text{candidate},\text{active},\text{promoted},\text{dormant},\text{forgotten}\}$$

**完整转移表**：

| 从 → 到 | 条件 | 权限 |
|---|---|---|
| candidate → active | 晋升判据（现行钙化/晋升链） | 系统 |
| active → promoted | 钙化 L3 / 黑钻 | 系统 |
| promoted → dormant | **不转移**（promoted 属免休眠） | — |
| active/promoted → dormant | `dormantPredicate` 复合谓词（§3.2） | 系统 |
| **dormant → active** | 唤醒算子 $W=1$ **且真被召回采用**（防抖：见 §十休眠迟滞） | 系统 |
| **any → forgotten** | **仅用户指令**（"别再提"） | **用户独占权限** |
| forgotten → * | **无出边（吸收态）** | 禁止 |

**suppressed 141 条迁移**：按 `suppression_reason` 分流 → `dormant`（自然衰减/测试隔离，可唤醒）或 `forgotten`（用户指令）；只改状态字段 + 写 `lifecycle_migrate` 事件，**不删行**。

**遗忘闭包（v2 新增，防二手泄露）**：

$$\sigma_{st}(m_{epi})=\text{forgotten}\ \Rightarrow\ \forall d\in\text{Derived}(m_{epi}):\ d\ \text{被重生成或标记 forgotten}$$

`Derived` 含：组摘要、钙化层、黑钻、dream_logs、dense 向量副本——否则被遗忘内容从摘要"二手泄露"= 信任事故。
**守卫**：遗忘一条后，全库（含摘要/黑钻/dream）检索其**独有关键词**，命中数 = 0。

## 三、记忆动力学（v2 修正 3 处公式错误）

### 3.1 强度演化 —— **增量形式**（修"跳变"错误）

$$s(\tau_{last}+\Delta)=s_{\min}+(s_{cur}-s_{\min})\,e^{-\Delta/\tau_n},\qquad \tau_n=\tau_0(1+\beta\ln(1+n))$$

- **每次只从上次状态推进**（$n$ 取最近更新时值），杜绝"召回后 $n$ 变大 → 从 $s_0$ 重算曲线重画"的跳变；
- **半群性质**（$n$ 固定时）：衰减 $\Delta_1$ 再 $\Delta_2$ = 一次衰减 $\Delta_1+\Delta_2$ —— 保证 `decay_log`（90,198 条）**分批与一次结果一致**；
- 召回强化（饱和，**显式声明 $r\in[0,1]$**）：$s\leftarrow s+\eta\,(1-s)\,r$；
- **函数**：`strengthDecay(s_cur, dt, n)` / `strengthBoost(s, r)`。

### 3.2 休眠谓词 —— **布尔名单**（修"V 与名单二选一"矛盾）

$$\text{Dormant}(m)\iff (s\le s_{\min}+\epsilon)\wedge(\Delta\tau_{last}>T_d)\wedge(n<n_0)\wedge\neg\text{Immune}(m)$$

$$\text{Immune}(m)\iff \text{黑钻}\ \vee\ \text{钙化L2+}\ \vee\ \text{is\_landmark}\ \vee\ \text{高情绪}$$

- **免休眠 = 逻辑或名单（可证明，能力断言直接可写）**；价值函数 $V(m)$（含 $\deg$ 归一化到 $[0,1]$）**仅用于排序信号**，不参与休眠判定；
- $\epsilon$ 容差消灭"strength 下限即 $s_{\min}$、`<s_min` 永假"问题；
- **函数**：`dormantPredicate(m, now)` / `immuneList(m)`；**守卫**：名单内任一成分 ⇒ `dormantPredicate=false` 恒真（M5）。

### 3.3 唤醒算子 —— **饱和**（修"越界"错误）

$$W(m|q)=\mathbb 1[\sigma_{st}\neq\text{forgotten}]\cdot\mathbb 1[\hat c\ge\theta_w\ \vee\ (\text{实体}\wedge\text{关键词})\ \vee\ \text{回忆问句}]$$

$$s'=s+\eta_w\,(1-s)\,W\cdot\hat c,\qquad \hat c\in[0,1]\ \text{（z 标定后相似度，见 §6.4）}$$

- 与召回强化**同构饱和**，$s'$ 恒 $\le 1$（与守卫"$s\in[s_{\min},1]$"一致）；
- **函数**：`wakeOperator(m, q)`；**守卫**：$\sigma_{st}=\text{forgotten}$ 时 $W\equiv0$；随机 $\hat c$ 下 $s'\le1$。

## 四、检索（v2 修正预算与守卫）

### 4.1 五路融合

$$\text{RRF}(m)=\sum_{r=1}^{5}\frac{w_r}{k+\text{rank}_r(m)},\quad k\approx60$$

$$\text{Score}(m|q)=\pi_{\ell(m)}(q)\cdot\text{RRF}(m)\cdot\big(\alpha+(1-\alpha)s\big)\cdot\big(1-p_{conf}(m)\big)\cdot\mathbb 1[\sigma_{st}\notin\{\text{dormant},\text{forgotten}\}\ \vee\ W=1]$$

- **v2 修正**：末项补 **dormant 判断**——否则休眠记忆会通过正常打分漏进默认召回；$W=1$ 为唯一唤醒入口；
- RRF 仅路间预融合，其后仍走配额+层保底；闸门阈值经 MW-Bench 重标定才上线（修正6）。

### 4.2 软路由 + **层保底独立性质**（v2 关键补强）

$$\pi_\ell(q)=\epsilon_\pi+(1-L\epsilon_\pi)\cdot\frac{\exp(\mathbf u_\ell^\top\phi(q)/T_r)}{\sum_j\exp(\mathbf u_j^\top\phi(q)/T_r)}$$

- 性质1：$\forall\ell,\ \pi_\ell\ge\epsilon_\pi$（乘数非零，属性测试）；
- **性质 2（v2 独立，真正防漏召回的保证）**：**每层至少 1 个召回名额**（层保底，非仅权重>0）——$\pi=0.05$ 对 $0.8$ 差 16 倍，top-k 截断下低权重层仍可能永不进。**落点 = 现行 RecallBus 层保底**（`budget.sand=2/gold=1/diamond=1/group=1` 正是此性质的实现），写成独立守卫：任意输入下每层 `selected` ≥ min(该层候选数, floor)。

### 4.3 查询改写门 —— **带间隔守卫**（v2 修"数学不成立"）

$$g=\sigma\big(\kappa_g[\hat c_{sim}-\theta_d]\big),\qquad \mathbf q'=\text{norm}(\mathbf q_t+g\,c_r\,\mathbf q_{t-1})$$

- **v2 守卫修正**：$\cos\le\theta_d-\delta_g\ \Rightarrow\ g\le\sigma(-\kappa_g\delta_g)$ 且 $\|\mathbf q'-\mathbf q_t\|\le 2g c_r$；取 $\kappa_g=10,\delta_g=0.2$ ⇒ $g\le0.119$。
  （原"cos<θ_d ⇒ 改写量<ε"不成立：连续函数在 θ_d 处 g=0.5。）
- **函数**：`rewriteGate(q_t, q_t1)` / `rewriteQuery(...)`。

### 4.4 动态预算 —— **B+2 + water-filling**（v2 修解析解错误）

$$\max_{h,m}\ a_H\ln(1+h)+a_M\ln(1+m)\ \text{s.t.}\ h+m=B$$

KKT：$\frac{a_H}{1+h}=\frac{a_M}{1+m}=\mu$，相加 $B+2=\frac{a_H+a_M}{\mu}$ ⇒ **正确解**：

$$h^*=\frac{B+2}{1+\rho}-1,\qquad m^*=\frac{\rho(B+2)}{1+\rho}-1,\qquad \rho=\frac{a_M}{a_H}$$

（v1 写 $B+1$ ⇒ $h^*+m^*=B-1$，每轮白丢 1 单位——**守卫 4 改为等式** $h^*+m^*=B$（clamp 前）才能检出此类错误。）

**water-filling clamp**（禁止两边独立截断，否则和超 $B$）：

- 若 $h^*<h_{\min}$：$h=h_{\min},\ m=B-h_{\min}$；
- 若 $m^*<m_{\min}$：$m=m_{\min},\ h=B-m_{\min}$；
- **可行性断言**：$B\ge h_{\min}+m_{\min}$（不满足即抛，不静默）。

$\rho$ 由指代依赖度（"那个/他/后来呢"→$a_H\uparrow$）与回忆问句（→$a_M\uparrow$）**规则近似**；压缩后 $B$ 不随历史缩水 ⇒ **切断 R3 正反馈**。
**函数**：`allocBudget(B, rho)`；**守卫**：clamp 前 $h^*+m^*=B$ 等式扫描 + water-filling 后 $h+m=B$ 恒成立 + 可行性断言。

## 五、双时态冲突消解（v2 改 append-only 版本行）

### 5.1 AsOf 回放

$$\text{AsOf}(f;T,T')\iff t_v^s\le T<t_v^e\ \wedge\ t_s\le T'<t_e$$

- 情景永不失效（§一拆分），事实按区间回放；**正反用例**（M4）：①"外公去世→外公健康失效" ②"去世前一年对话仍可检出"。

### 5.2 冲突判定 —— **须有效期重叠**（v2 修"recency 坑"）

$$\text{Conflict}(f_{new},f_{old})\iff key_{new}=key_{old}\ \wedge\ [t_v)_{new}\cap[t_v)_{old}\neq\varnothing\ \wedge\ val_{new}\neq val_{old}$$

- **按事件时间而非写入时间**——"外公**以前**身体很好"（新写入、过去时间）**不推翻**"已去世"；
- **仅单值键**走冲突逻辑（存殁/住址互斥）；多值键（爱好/朋友）共存不冲突；
- 事件时间模糊 → $[t_v^s,t_v^e)$ 带精度区间；解析失败回退 $t_{tx}$ + `v_inferred` 标记。

### 5.3 分段处置 —— **append-only 版本行**（v2 修"原地改写 vs 旧数据不动"矛盾）

$$p_{conf}=\sigma\big(b_0+b_1\text{NLI}(f_{new},f_{old})+b_2\text{src}(f_{new})+b_3\text{recency}\big)\quad(\text{NLI 第一版规则近似})$$

| $p_{conf}$ | 动作（**均为追加，旧行永不改**） |
|---|---|
| $\ge\theta_{hi}$ | **追加新版本行**：$ver{+}1$、带 $t_v^e$、`superseded_by` 指针；旧行原样 |
| $[\theta_{lo},\theta_{hi})$ | 追加 `downweight` 事件，$w=1-p_{conf}$，进待审 |
| $<\theta_{lo}$ | 共存 |

- **可逆 = 事件流逆操作**：`invalidate` ↔ 追加 `revalidate`/新版本，**旧数据不动** —— 与哈希链、事件溯源三者一致（v1 的"旧行写 invalidated_at"自相矛盾，已废）；
- **函数**：`conflictAction(f_new, f_old)`；**守卫**：失效后回滚，状态校验和与失效前一致。

## 六、完整性（v2 修"链与删除冲突"）

### 6.1 哈希链 —— **分段 + 墓碑 + 外部锚定**（v2 修"合法删除误判"）

$$H_i=\text{SHA256}(\text{canon}(x_i,t_{tx,i},belong_i,src_i)),\qquad C_i^{seg}=\text{SHA256}(C_{i-1}^{seg}\|H_i)$$

- **v1 单链的致命问题**：P170 隔离 30 天后物理删 / 用户要求遗忘删 —— 删第 $i$ 条全链失配，**检出的是自己的合法删除**。三层组合：
  1. **墓碑化**：删除只清 $x$，保留 $H_i$ + tombstone 标记，链仍可验证；
  2. **分段链**：按日 / 按 `belong` 分段独立成链，验证成本有界、断点定位更快；
  3. **外部锚定**：链头哈希定期写**库外**（日志/异机）——否则能改库者可重算整链，"篡改可检"失效；
- **canon() 规范入 ADR**：字段顺序、**Unicode NFC 归一**、时间戳 ISO8601 毫秒格式 —— 否则跨版本同记录哈希不同；
- 可变状态（强度/次数）**旁表**，不入链（修正7 维持）；
- **函数**：`chainHash(prev, immutableCore)` / `tombstone(id)`；**守卫**：篡改注入断点定位正确 + **合法删除不报篡改** + canon 跨版本一致性。

### 6.2 重建不变量 —— **确定性前提**（v2 补三条件）

$$S_T=\text{fold}(\text{apply},S_0,\{e_1..e_T\}),\qquad \Delta_{rebuild}=d(\text{Index}(S_T),\text{Index}_{live})=0$$

- **apply 必须是纯函数**：①不读墙钟（时间入事件载荷）；②**LLM 产物（mem_class、dream 摘要）作为事件载荷记录，重放不再调 LLM**；③$d(\cdot,\cdot)$ 比**记录集对称差 + 字段校验和**，不比 HNSW 图结构（依赖插入顺序）；
- 逻辑视图 + outbox（原表写入不变），**定期对账演练** $\Delta\neq0$ 即告警（修正8 维持）。

### 6.3 版本切换 —— **先归一再混合**（v2 修"尺度不同直接加权"）

$$\text{Score}=(1-\gamma)\,\widetilde{\text{Score}}_{old}+\gamma\,\widetilde{\text{Score}}_{new}$$

- $\widetilde{\cdot}$ = **各路 z 标准化分数或名次 RRF**（两模型尺度分布不同，直接加权无意义）；
- 双写期**只有旧向量**的记忆显式走"仅旧路"分支；$\gamma:0\to1$ 可随时退，免停服；
- **守卫**：$\gamma=0$ 时与旧路**名次逐位一致**。

### 6.4 余弦标定 —— **z 值按 model@ver**（v2 修"绝对阈值必失效"）

$$\hat c=\Phi\Big(\frac{\cos-\mu_{bg}}{\sigma_{bg}}\Big),\qquad \mu_{bg},\sigma_{bg}\ \text{按 model@ver 各存一份}$$

- bge 系中文模型余弦分布整体偏高（无关句对常 >0.5）——$\theta_w=0.45$ 会让休眠几乎全被唤醒、$\theta_d=0.35$ 恒判同话题；
- 改用**相对背景分布的分位数**，换模型重标定，与向量版本绑定一脉相承。

## 七、置信度与评测（v2 修统计三处）

### 7.1 置信度 —— 原始分 + 在线路数 + 标定

$$\text{conf}=\sigma\Big(a_1 z(S_1^{raw})+a_2 (S_1^{raw}-S_2^{raw})+a_3\frac{|\{r:m_1\in\text{Top}_k(r)\}|}{R_{online}}-b\Big)$$

- **用各路原始分**（dense 校准余弦、BM25 分），不用 RRF 融合分（RRF 只含名次、头名全第 1 时是常数）；
- 第三项分母 = **在线路数 $R_{online}$**（降级 3 路时除 3，不写死 5）；
- $\sigma$ 输出用 MW-Bench 做 **Platt / 保序回归标定**并报告 **ECE**——否则 0.75/0.4 档位线无统计含义（P2）；
- 输出仍按角色口吻三档（补充A 维持），召回层出数值、MW-Express 转文案。

### 7.2 门禁 —— **配对检验三态**（v2 修"$\delta$<噪声"）

- $n=50$、成功率 80% 时两独立样本差值 SD≈8%，**$\delta=3\%$ 低于噪声 = 掷骰子**；
- 新旧版本**跑同一批题**，**配对检验**（McNemar / bootstrap 对不一致题）；
- **三态门禁**：

| 差值 95% 区间 | 决策 |
|---|---|
| 上界 < 0（显著退化） | **自动阻断** |
| 跨 0 但下界 < $-\delta$ | **转人工审**，不自动放行 |
| 下界 $\ge-\delta$ | 放行 |

- **只有留出集参与放行**；**留出集限用次数 + 定期轮换新题**（防"间接调参"污染）；
- Wilson 区间（下界表述）保留作**报告口径**，放行用配对检验。
