## 一、统一状态空间

一条记忆：

$$m=\big(x,\ \mathbf{e},\ \mathbf{p},\ \kappa,\ [v_s,v_e),\ t_{tx},\ s,\ n,\ \tau_{last},\ \lambda,\ \mathbf{c}\big)$$

| 符号 | 含义 | 现有字段映射 | 状态 |
|---|---|---|---|
| $x$ | 原文（不可变） | `raw_input` | ✅ 已有 |
| $\mathbf{e}$ | dense 内容向量，带 `model@ver` | **新增**（M3 影子模式建） | 🆕 |
| $\mathbf{p}$ | 40D 感知向量 | `perception_40d` / `perception_v40_direct` | ✅ 已有 |
| $\kappa$ | 语义键（如 外公·存殁） | **新增**（M4 N2） | 🆕 |
| $[v_s,v_e)$ | 事件有效时间（valid time） | **新增**（修正2，不复用 Foresight `valid_*`） | 🆕 |
| $t_{tx}$ | 系统获知时间（transaction time） | `created_at` / 新 `invalidated_at` | ✅/🆕 |
| $s,n,\tau_{last}$ | 强度/召回次数/上次召回 | `effective_strength` / `recall_count` / `last_recalled_at` | ✅ 已有 |
| $\lambda$ | 生命周期状态 | `lifecycle_state`（扩态见 §二） | ✅ 扩展 |
| $\mathbf{c}\in[0,1]^5$ | 多标签类型（软） | `mem_class`（新增，仅加权不过滤——修正4） | 🆕 |

## 二、生命周期状态机（含吸收态）

$$\lambda\in\{\text{candidate},\ \text{active},\ \text{promoted},\ \text{dormant},\ \text{forgotten}\}$$

- **`forgotten` 是吸收态**：任何唤醒算子无法离开 —— 数学上落实补充B「用户要求忘记 ≠ 自然遗忘」，**防信任事故**；
- **现有 `suppressed` 141 条迁移规则**（本附录补充）：按 `suppression_reason` 分流——自然衰减/测试隔离类 → `dormant`（可唤醒）；用户指令类 → `forgotten`（吸收态）；迁移只改状态字段不删行，写 `lifecycle_migrate` 事件入流。

**守卫**：`state-machine.test` —— 任意唤醒序列（含强线索穷举）后 $\lambda=\text{forgotten}$ 仍成立（M5）。

## 三、记忆动力学

### 3.1 强度演化（遗忘 + 间隔强化）

$$s(t)=s_{\min}+(s_0-s_{\min})\,e^{-\Delta t/\tau_n},\qquad \tau_n=\tau_0(1+\beta\ln(1+n))$$

召回强化（饱和）：$s\leftarrow s+\eta(1-s)\cdot r(m|q)$，$r$=本次召回相关度。

- 落点：**升级现有** `FiveStageGate:193 decayed`（现为无 $n$ 项的简单衰减）+ `applyRecallFeedback`（现为 `recall_count++`，补 $s$ 饱和项）；
- **函数**：`strengthDecay(s0, dt, n)` / `strengthBoost(s, r)`；
- 性质：$s\in[s_{\min},1]$ 不越界（**守卫**：随机 $s_0,n,\Delta t$ 扫描边界，M5）。

### 3.2 价值函数与休眠谓词（修正1 形式化）

$$V(m)=w_1\mathbb 1[\text{黑钻}]+w_2\tfrac{\text{钙化级}}{3}+w_3\,\text{emo}(m)+w_4\,\deg(m)$$

$$\text{Dormant}(m)\iff (s\le s_{\min}+\epsilon)\wedge(\Delta\tau_{last}>T_d)\wedge(n<n_0)\wedge(V(m)<V_{\text{immune}})$$

- **$\epsilon$ 容差正是修正1 的核心**（`strength` 下限就是 $s_{\min}=0.05$，`<0.05` 永假 → `≤ s_min+ε` 可判）；
- $\deg(m)$=实体图度数（`memory_entities` 关联数）——关联多不易沉睡；
- **函数**：`memoryValue(m)` / `dormantPredicate(m, now)`；
- **守卫**（免休眠名单，能力断言）：黑钻 ∨ 钙化L2+ ∨ `is_landmark` ∨ 高情绪 ⇒ `dormantPredicate=false` 恒成立（M5）。

### 3.3 唤醒算子

$$W(m|q)=\mathbb 1[\lambda\neq\text{forgotten}]\cdot\mathbb 1[\cos(\mathbf e_q,\mathbf e_m)\ge\theta_w\ \vee\ (\text{实体}\wedge\text{关键词})\ \vee\ \text{回忆问句}]$$

$$s'=s+\eta_w\cdot W\cdot\cos(\mathbf e_q,\mathbf e_m)$$

- 唤醒后临时参与，**真被采用才回 active**；
- **函数**：`wakeOperator(m, q)`；**守卫**：$\lambda=\text{forgotten}$ 时 $W\equiv 0$（与 §二吸收态同一测试）。

## 四、检索

### 4.1 五路融合（修正6：RRF 仅路间预融合）

$$\text{RRF}(m)=\sum_{r=1}^{5}\frac{w_r}{k+\text{rank}_r(m)},\quad k\approx60$$

$$\text{Score}(m|q)=\underbrace{\pi_{\ell(m)}(q)}_{\text{层权重}}\cdot\text{RRF}(m)\cdot\big(\alpha+(1-\alpha)s\big)\cdot(1-p_{\text{conf}}(m))\cdot\mathbb 1[\lambda\neq\text{forgotten}]$$

- 乘性 ⇒ **硬遗忘一票否决归零**、冲突按概率降权；
- RRF 之后**仍走配额+层保底**（现行 RecallBus 结构不动）；五级闸门阈值**必须经 MW-Bench 重标定才可上线**（ADR-024 修正6 = 上线 gate）；
- **函数**：`rrfFuse(ranks, weights)` / `finalScore(m, q)`。

### 4.2 软路由（修正4 形式化）

$$\pi_\ell(q)=\epsilon_\pi+(1-L\epsilon_\pi)\cdot\frac{\exp(\mathbf u_\ell^\top\phi(q)/T)}{\sum_j\exp(\mathbf u_j^\top\phi(q)/T)}$$

- **可证性质**：$\forall\ell,\ \pi_\ell\ge\epsilon_\pi>0$ ⇒ 意图分类错一次**也不会永久漏召回**；
- **函数**：`layerWeights(intent)`；**守卫**（属性测试）：随机 $\phi(q)$ 下无零权重（M4）。

### 4.3 查询改写带话题漂移门（修正5 形式化）

$$g=\sigma\big(\kappa[\cos(\mathbf q_t,\mathbf q_{t-1})-\theta_d]\big),\qquad \mathbf q'=\text{norm}(\mathbf q_t+g\lambda_c\mathbf q_{t-1})$$

- 话题延续 $g\to1$ 并入上文；切换 $g\to0$ 保持原样；40D 同理 $\mathbf p'_q=\text{norm}(\mathbf p_t+g\lambda_p\mathbf p_{t-1})$；
- **函数**：`rewriteGate(q_t, q_t1)` / `rewriteQuery(...)`；**守卫**：$\cos<\theta_d$ 时改写量 $<\epsilon$（M2）。

### 4.4 动态预算（R3 形式化解析解）

$$\max_{h,m}\ a_H\ln(1+h)+a_M\ln(1+m)\ \text{s.t.}\ h+m\le B,\ h\ge h_{\min},\ m\ge m_{\min}$$

令 $\rho=a_M/a_H$：$\ h^*=\frac{B+1}{1+\rho}-1,\quad m^*=\frac{\rho(B+1)}{1+\rho}-1$，再 clamp。

- $\rho$ 由**指代依赖度**（"那个/他/后来呢"多 → $a_H\uparrow$）与**检索类型**（回忆问句 → $a_M\uparrow$）决定——**第一版规则近似**（不训模型）；
- 替代固定 A30/B50/C20 与 `C=histChars×1.0`（**切断 R3 正反馈**：压缩后 $B$ 不随历史缩水，$\rho$ 反而给记忆更多）；
- **函数**：`allocBudget(B, rho)`；**守卫**：$h^*+m^*\le B$ 边界扫描 + clamp 后非负（M2）。

## 五、双时态冲突消解（N2 · 业主令：不许简化版）

### 5.1 AsOf 回放

$$\text{AsOf}(f;T,T')\iff v_s\le T<v_e\ \wedge\ t_s\le T'<t_e$$

- 默认 $T=T'=\text{now}$；历史求证查任意 $(T,T')$；**去世前一年的对话在 $T$ 取那一年时依然有效**；
- **函数**：`asOfFilter(f, T, T')`；**守卫**（M4 正反用例）：①"外公去世→外公健康失效" ②"去世前一年的对话仍可检出"。

### 5.2 冲突概率分段处置（可逆）

$$p_{\text{conf}}=\sigma\big(b_0+b_1\text{NLI}(f_{新},f_{旧})+b_2\text{src}(f_{新})+b_3\text{recency}\big)$$

$$\text{action}=\begin{cases}\text{失效：写 } v_e,\ \text{superseded\_by}, & p\ge\tau_{hi}\\ \text{降权待审：}w=1-p, & \tau_{lo}\le p<\tau_{hi}\\ \text{共存}, & p<\tau_{lo}\end{cases}$$

- **NLI 项第一版规则近似**（关键词矛盾表：存殁/职务/地址对立法），后续可换模型；
- **可逆性 = 事件流逆操作**：`invalidate` 事件 ↔ 追加 `revalidate` 事件，**旧数据不动**；
- **函数**：`conflictAction(f_new, f_old)`；**守卫**：失效后可 revalidate 恢复且状态校验和一致（M4）。

## 六、完整性

### 6.1 不可变内核哈希链（修正7 形式化）

$$H_i=\text{SHA256}(\text{canon}(x_i,t_{tx,i},\text{belong}_i,\text{src}_i)),\qquad C_i=\text{SHA256}(C_{i-1}\|H_i)$$

- **只盖不可变字段**（原文/时间/归属/来源）；`recall_count`/`effective_strength` 等可变状态**旁表**，不入链；
- 链式 ⇒ 中间任一条被改，后续全部失配、**断点可定位**；
- **函数**：`chainHash(prev, immutableCore)`；**守卫**：篡改注入测试——改任意一条，检出位置正确（M1）。

### 6.2 事件溯源重建不变量（修正8 形式化）

$$S_T=\text{fold}(\text{apply},S_0,\{e_1..e_T\}),\qquad \Delta_{\text{rebuild}}=d(\text{Index}(S_T),\text{Index}_{\text{live}})=0$$

- 逻辑视图 + outbox（原表写入不变），**定期对账演练**，$\Delta\neq0$ 即告警；
- **函数**：`rebuildIndex(events)` / `reconcile()`；**守卫**：M1 起每周演练，差异>0 告警（不是纸面承诺）。

### 6.3 向量版本安全切换

$$\text{Score}=(1-\gamma)\text{Score}_{v_{old}}+\gamma\,\text{Score}_{v_{new}},\quad\gamma:0\to1$$

- 在线双写、随时可退、免停服（**回答 ADR-024 裁决③**）；
- **函数**：`blendScores(gamma, ...)`；**守卫**：$\gamma=0$ 时与旧路逐位一致（M3）。

## 七、置信度与评测

### 7.1 召回置信度（补充A 形式化）

$$\text{conf}=\sigma\Big(a_1z(S_1)+a_2(S_1-S_2)+a_3\tfrac{|\{r:m_1\in\text{Top}_k(r)\}|}{5}-b\Big)$$

| conf 区间 | 输出策略（角色口吻，禁系统腔） |
|---|---|
| ≥0.75 | 直接陈述 |
| [0.4,0.75) | "我好像记得……" |
| <0.4 | 角色式承认不确定，**不编造** |

- 召回层只出数值，**MW-Express 表达层转角色文案**；
- **函数**：`recallConfidence(top1, top2, crossRoute)`。

### 7.2 Wilson 区间门禁（修正9 形式化）

$$\hat p_\pm=\frac{\hat p+\frac{z^2}{2n}\pm z\sqrt{\frac{\hat p(1-\hat p)}{n}+\frac{z^2}{4n^2}}}{1+\frac{z^2}{n}}$$

- **通过标准 = 下界**：$\text{Block}\iff \hat p^{\text{new}}_-<\hat p^{\text{base}}_--\delta$；**只有留出集的下界参与放行**；
- 数学依据：$n=10$、成功率 80% 时 95% 区间 $[0.49,0.94]$ 宽约 45pp（"≥4/5"几乎无信息）→ 40–50 组（宽度 22pp）；
- **函数**：`wilsonCI(k, n)` / `gateDecision(...)`；**落点**：MW-Bench 接 Harness **S6**（M0 已建题库，S6 门禁 M1 起生效）。
