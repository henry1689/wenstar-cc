# ADR-MEM-003: 记忆生命周期与受控遗忘法案（M 层基础法案）

- **版本**: v1.0｜**状态**: ✅ 已定稿（业主 2026-11-02 会话裁决：采纳乙案 + 账本永久 + 参数照准 + 四补强 + 三 P0 红线）

- **前置**: ADR-MEM-002（MemSym 双通路记忆共生协议）、ADR-010 D2/D8、ADR-012 D6、太虚户籍法第十一条（本 ADR 修订之）

## 一、立法背景与目标

原第十一条「卷宗只增不删」以**静态档案保全**为唯一取向，与人脑真实记忆机制相悖：人脑并不保存发生过的一切，而是**只保存被巩固过的一切**——大量情节记忆在睡眠巩固中被衰减、提炼、丢弃，只有跨过固化阈值的部分进入长期。原条文在执行层已产生四处模糊（测试污染无豁免、状态化与删除混同、合法删除程序无明文、检索侧过滤义务未固化），且面对记忆系统的**存储与索引无限膨胀**无任何出口。

本法案目标：**把「遗忘」从事故变成设计**——未钙化记忆获得生命周期、到期受控删除；钙化与人格核心永生；遗忘与 MemSym 默契生长共用同一闭环。

**推翻范围**：原第十一条第(一)(二)(四)款（卷宗/对话/绑定的绝对只增不删）废止；**账本条款除外保留**（§三.A.5）。本法案仅管理**体验侧记忆条目生命周期**，不覆盖系统治理审计台账、禁忌规则（FG taboos 域）、人格核心信条。

## 三、分层架构（谁永生、谁到期）

### A 层 · 永生层（不设生命周期，不进入遗忘状态机扫描）

1. **钙化记忆**：`calcium_score ≥ θ_permanent`（0.85）；
2. **人格核心**：dossier 全部字段（basicInfo / selfProfile / personalityCore 信条 / 固有完整人设）；
3. **语义晋升产物**：经 M7 归纳提炼进 FG/dossier/KB 的事实（「忘掉对话、留下结论」）；
4. **黑钻金库 vault** 记录（既有长期层）；
5. **审计变更账本 + 删除追溯日志**：**永久只增不删，不纳入生命周期**（业主裁决②）——它是系统治理台账与问责根链，不是体验侧记忆（人脑类比：不是相处记忆，是系统自身的事务台账）；带 TTL 将使删除/钙化/ADR/权限变更全部失去可追溯性，回滚与串扰溯源直接废掉。磁盘压力极大时走**冷归档迁移**（转离线存储），不走逻辑删除。

**MemSym 取用边界**：A 层被 MemSym 取元素**不触发任何遗忘流程**（元素池来源优先级不变：FG 档案 > M7 离线巩固产出的语义元素 > B 层新鲜未钙化碎片；B 层碎片仅是临时素材）。

### B 层 · 生命周期层（乙案 —— 业主裁决①）

**范围**：未达标钙化的记忆碎片（memories）**+ 低钙化对话组原文**（`block_calcium_score < θ` 的 dialog_groups / conversations）。

**选择乙案的理由**：最贴合人脑（记住结论、偏好、感受，而非每句原文）；与 MemSym 通路 B 天然匹配（复用原子元素而非永久保全原文）；直击最大存储膨胀源（对话组体量第一），索引压力大幅下降。甲案（仅删碎片）治标不治本。

**乙案双防护（必须写入规范）**：
1. **A 层锚点豁免**：任何对话组只要包含**一条 A 层永生锚点**（高钙记忆、户籍核心条目、金库引用），**整组豁免**进入 B 层生命周期，不删；
2. **溯源链保全**：墓碑元数据必须记录 `dna_root_id`，保留溯源链路，不凭空断根。

### C 层 · 墓碑层

见 §四状态机与 §八执行程序。

## 四、生命周期状态机（含 expiring 预萃取晋升钩子）

```
 fresh ──(无二次提取·τ 衰减)──▶ weakening ──▶ expiring ──▶ tombstone ──▶ purged(物理清除)
   ▲                               │              │             │
   └────(有效召回·再巩固重置原点)────┘              │             └──(墓碑期内人工恢复)──▶ fresh
                                                   │
                                     ┌──(M7 归纳萃取成功)──▶ 永生层 A（脱离遗忘循环）
                                     └──(萃取失败)────────▶ tombstone
```

状态语义（神经心理学注释）：
- **fresh**：新编码，海马短期缓冲刚入队，未经睡眠巩固筛选；
- **weakening**：自然衰减，无二次提取强化，活性缓慢下滑；
- **expiring**：临近失效阈值 —— **关键钩子：M7 睡眠扫描优先把本批送入语义归纳管线尝试晋升**。一条记忆快忘之前，系统最后一次机会提炼语义元素送入 FG/dossier/KB：**提炼成功 → 晋升 A 层永生，跳出遗忘循环；失败 → 继续走向墓碑、删除**。这复刻人脑睡眠巩固：睡眠扫描弱记忆，能提炼成语义就固化，不能就丢掉细节。
  🔗 **MemSym 批次接入点**：批 γ（要素池 + 萃取器）阶段接入本钩子 —— B 层记忆消亡前是 MemSym 元素池的**最后补给源**；
- **tombstone**：从检索索引摘除，对外不可召回，仅保留审计元数据，可回滚恢复；
- **purged**：物理清除，不可恢复。

**已晋升 A 层的记忆不再进入本状态机扫描**（边界约束）。

## 五、TTL 与记忆活性公式

```
τ = τ₀ × (1 + α·Ca) × (1 + β·ln(1 + recallCount)) × (1 + γ·arousal)     并满足 τ ≤ τ_max

expires_at = last_reinforced_at + τ
strength(t) = exp(−Δt / τ)          // Δt 自最近强化起算
遗忘判据：strength(t) < θ_forget → expiring
```

| 参数 | 初值 | 含义 |
|---|---|---|
| τ₀ | 30 天 | 基准衰减常数 |
| α | 4.0 | 钙化乘数（Ca=0.9 → τ×4.6，高钙天然长寿） |
| β | 0.5 | 提取强化（每次有效召回 +50% 间隔——间隔重复效应） |
| γ | [0,1] | **arousal 主乘数**（§六） |
| **τ_max** | **365 天** | **封顶（业主补强①）** |
| θ_permanent | 0.85 | 永生钙化门槛 |
| θ_forget | 0.03 | 遗忘强度阈值 |

**τ_max 封顶的法理（关键分界）**：高钙 + 反复召回 + 高唤醒会让 τ 无限放大而失去生命周期意义。封顶后——**未跨过 0.85 钙化阈值的记忆，无论被唤起多少次、情绪多强，最多一年后进入遗忘流程**。永生层是**钙化硬门槛（巩固晋升事件）**，不是靠无限拉长 TTL 绕过去；**高被关注 ≠ 自动永生**。

**两套独立变量边界（防逻辑缠绕）**：
- `calcium_score`：巩固程度、是否值得长期沉淀 —— 供 MemSym、M7 巩固、通路 A/B 召回增益使用；
- `strength(t)`：**B 层遗忘状态机专用**，仅代表「未巩固条目当前剩多少可检索活性」；
- 🔴 `strength(t)` **只做状态推进判断，禁止用于钙化分换算**——两套量纲永不互转（P087 双分值混乱红线的延伸）。

**有效召回的双动作（两套子系统的唯一耦合点）**：
一次召回同时做两件**互相独立**的事：
1. `calcium_score += 增益`（MemSym 规则：通路 A 高系数 / 通路 B 低系数，沿用 MemSym 原有系数）；
2. 刷新 `last_reinforced_at`，重置衰减计时起点（再巩固）。

## 六、情绪显著性（VAD）约束

- **只取 arousal（唤醒度）作 τ 主乘数**，γ∈[0,1]；
- **valence 正负只打标签，不影响 TTL** —— 理由：高唤醒（强烈情绪，无论眷恋、震撼、不安）才提升记忆留存窗口；单纯正向/负向效价在心理学上不直接决定记忆存活时长，避免情绪极性带来不合理偏置（防「只记住愉快的/只记住悲伤的」价值偏置）。

## 七、MemSym 联动校准（上下游关系，不得独立跑）

**分工**：MemSym 负责「记忆怎么被取用（双通路、默契沉淀、元素萃取）」；本法案负责「记忆什么时候消失、谁能留下来」。

| 触发 | MemSym 动作 | 本法案动作 |
|---|---|---|
| 通路 A（主动回忆）召回 | 钙分高系数增益 | 刷新 `last_reinforced_at`，重置衰减时钟 |
| 通路 B（元素浸润）拾取 | 钙分低系数增益 | 同上刷新计时 |

✅ **「默契生长」与「记忆筛选」是同一个闭环**：B 通路潜移默化的默契呼应同样延长底层碎片存活——经常被拿来共情呼应的片段不容易被洗掉；长期闲置、从未被对话唤起的碎片慢慢消亡（契合亲密共生目标）。

**总开关隔离**：遗忘机制整体挂 `MEMORY_FORGET_ENABLED`，关闭即回退原只增不删模式（保持回滚安全）。

**落地顺序（批 α~ε 影响）**：
- 批 α（MemSym 文书包/法理）：**不受影响**；
- 批 γ（要素池 + 萃取器）：接入「expiring 预萃取晋升钩子」；
- 遗忘批处理执行、墓碑、配额、TTL 调度：作为 **MemSym v1.1 配套 M 层升级或独立 M 层批次**落地；
- v1.0 MemSym 先跑通双通路，遗忘机制作为**可开关增强模块**。

## 八、执行程序与 P0 工程红线

### 删除执行五道闸（P029 程序成文化）

1. **先忘记、后销毁**：进入 tombstone 即从检索索引摘除（检索立即不可见），物理删除延后；
2. **墓碑期**（30 天）：墓碑行保留最小元数据 `{id, deleted_at, reason, dna_root_id, calcium, last_recall}` —— 恢复窗口 + 删除证据；期满才物理清除；
3. **硬配额**：单日删除上限 500 条，防级联 bug 越权删；
4. **批前完整性校验 + 备份快照 + 事务原子性**（SQLite 单库事务，批内原子）；
5. **全局总开关** `MEMORY_FORGET_ENABLED=0`：一键回退原只增不删模式。

### 🔴 三条 P0 工程红线（第十一条配套约束）

1. **墓碑期只读**：进入 tombstone 后 `calcium_score`/`recall_count`/`last_recalled_at` 一律不再更新；墓碑状态不接受正常召回带来的强化；**仅主动恢复操作**可将条目推回 fresh 重新进入循环；
2. **DNA 锚点跨引用保护**：B 层记忆若是多条永生 A 层记忆的 `dna` 溯源根节点 → **禁止物理删除，自动豁免 B 层周期**（防永生记忆溯源链断裂）；
3. **遗忘不是惩罚机制**：生命周期与「负面/禁忌记忆」**无关**——禁忌、taboo 条目由 FG 档案 taboos 域管控，不属于遗忘逻辑；遗忘只由**巩固程度、提取频率、情绪显著性**三者驱动，**不带价值评判**，防系统自动洗掉不愉快但重要的记忆。

## 十一、法条修订定稿（太虚户籍法 第十一条 替换全文）

> **第十一条　记忆生命周期与受控遗忘**
>
> 记忆按巩固层级分为永生层与生命周期层。钙化分 ≥ θ_permanent、人格核心档案 dossier、语义晋升产物、黑钻金库 vault 记录，归入永生层，不受生命周期约束，永久保留；审计变更账本、删除追溯日志作为治理台账，永久只增不删。
>
> 生命周期层包含未达标钙化的记忆碎片、低钙化对话组原文；自最近一次强化时间起获得存活周期 τ，τ 由基准时长、钙化分值、提取频次、情绪唤醒度联合计算，设置 τ_max 上限。每次有效召回（通路 A、通路 B 元素复用）重置强化时间原点，触发再巩固，延长存活周期。
>
> 生命周期内记忆持续计算记忆活性 strength(t)；活性低于遗忘阈值 θ_forget，进入临期 expiring 状态。临期条目优先送入睡眠巩固管线尝试语义归纳萃取；萃取成功晋升至永生层，脱离遗忘循环；萃取失败转入墓碑状态。
>
> 墓碑状态条目从检索索引摘除，对外不可召回，保留最小元数据用于恢复与审计；墓碑期满，执行物理清除，数据不可恢复。墓碑期内支持人工触发恢复，恢复后重回 fresh 状态。
>
> 遗忘执行受硬配额、批前完整性校验、事务原子性、备份快照保护；设置全局总开关 MEMORY_FORGET_ENABLED，关闭时回退至原只增不删模式。
>
> 原第十一条「卷宗只增不删」相关条款废止；本条款仅管理体验侧记忆条目生命周期，不覆盖系统治理审计台账、禁忌规则、人格核心信条。
