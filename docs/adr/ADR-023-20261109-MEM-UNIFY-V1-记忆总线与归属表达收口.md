# ADR-023 MEM-UNIFY-V1：记忆总线、归属单一源与表达法收口

- 日期：2026-11-09
- 状态：已采纳（批0–批4 已落地，批6 数据治理待停服窗口）
- 前置：ADR-008（钙化统一）、ADR-010（对话块）、ADR-013（状态真源）、ADR-014（回忆表达三档）、ADR-016（命名空间隔离）、ADR-019（casual 轻档）、ADR-MEM-002（MemSym 双通路）
- 依据：`docs/记忆系统统一任务书-V1.md`（MEM-UNIFY-V1）与业主 2026-11-08 裁决 D1–D10；批0–批4 协作记录 P155–P160

## 1. 背景与 S1 实测（2026-11-08，只读基线）

| 事实 | 证据 |
|---|---|
| 写入一轮多写 | M9 `evt_*` + persistence `mem_*` + 砂金→金库 1:1 复制 + 重复黑钻晋升 |
| 去重键按 `leaf_zone` 隔离 | 同角色跨 taxonomy zone 同文可重复入库 |
| 晋升状态不一致 | 665 条 `promoted_to_diamond=1` 但无 active 黑钻；95 条反向 |
| 归属策略多份手写 | `buildPolicePolicy` / `SQLiteAdapter` / `UnifiedSearchEngine`×2 / `chat.ts` / `retrieval-stage` 各自拼 SQL |
| 三库召不回 | casual 97.7% 早退；V14 陈旧快照抢占；深度收集只覆盖三仓且硬顶 12 条/110 字 |
| 表达被压制 | 44 处旧反编造措辞；会晤固定 `recaller`「绝对禁止编造」 |

## 2. 决策

1. **写入一次、派生另算**：同一语义单元只写一份（`memories` 由 persistence 一次写入；`WorkingMemory.persistEvents=false`）；删除砂金→金库 1:1 复制（D2）；黑钻晋升唯一路径 = `VaultManager`。
2. **去重键唯一**：`(belong_uuid, role, normalized_text)`（NFKC + 零宽清理 + 空白折叠）；user/assistant 互不拦截，同角色跨 zone 拦截。
3. **晋升单向门以 active 黑钻为唯一真源**：仅与 active 合并；INSERT 后 `EXISTS(active)` 才置 `promoted_to_diamond=1`；降级/删除均按 active 判据。
4. **归属单一源**：`policyFor(domain, visibleUuids, { enforce, ownerMode })` 是唯一产出处；`allowUnowned` 降为派生；知识无归属 = 共享（D5）；私有域新写入无归属 → 拒写 + 健康计数；`memarch` 命名空间解析失败 → fail-closed。
5. **召回总线唯一出口**：`src/m4/recall/recall-bus.ts` 统一四模式（casual/standard/deep/proactive）、层保底、单一五级闸门、单点反馈；V14 移出生产主链（D1）。
6. **深度整编收集最大化**：`sweepAllStores` 覆盖砂金/黑钻 active/知识（自有+共享）/对话原文 + 证据层（FG 档案/作品/记事）；取消 12 条/110 字硬顶，改字符预算（默认 6000 字、单条 400 字）；`vault_log` 退出召回（D3，仅 auto_induct 作事实锚点）。
7. **主动回忆为独立纯规则信号层**：`proactive-trigger.ts` 产出节日/纪念日/情绪/日常/话题关联信号（零 LLM）；文案仍由 `MEMORY-LAW-V1` 单源组装；`[Proactive]`/`[DeepSweep]` 日志。
8. **表达法单一源**：`src/m5/prompts/memory-expression-law.ts`；三档/三重奏/憧憬自由/双模式义务/守卫禁令；任何 prompt/守卫不得以反编造之名压制表达。
9. **指令与记忆分离**：深度素材包、结晶令、三档协议、默契元素、主动回忆指令在召回总线中归 `other`，不占三层名额。

## 4. 后果

**正面**
- 归属与表达各只有一个真源，新增路径不再需要复制规则；
- 召回失败可归因（每路独立日志 + 层保底缺口），不再「静默变少」；
- 深度回忆不再因固定条数/字数丢掉候选，证据层（档案/作品/记事）进入回忆视野。

**代价 / 边界**
- 私有域写入门槛提高：调用方漏传字段会写失败（fail-closed，计入 `getMemoryWriteHealth()`）；
- 存量脏数据（无归属/重复/晋升不一致）仍未清理，部分召回仍受存量影响 → 批6；
- 行为指标依赖 LLM，存在波动；探针以「法源口径」判定（带标记的"细节记不清"不算回避）。
