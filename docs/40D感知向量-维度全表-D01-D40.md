## 〇、总定义

**40D = 40 维感知向量（`PerceptionV40`）**：WenStar OS 用来表示「瑶灵此刻的主观体感状态」的统一坐标系。

| 项 | 口径 |
|---|---|
| 维度总数 | `PERCEPTION_40D_DIM = 40`（40 个命名键，固定键序 `PERCEPTION_40D_KEYS`） |
| 编号基准 | D1 开头（对齐 spine.proto 存储坐标），裸 key 与瑶光 dim_key **绝对一致**（命名铁律） |
| 值域 | **[0,1] 归一化**；仅 **D36/D37 双极 [-1,1]** |
| 归一化锚点 | 瑶光 `standard_range` 中点（baseline） |
| 定义依据 | 40D = spine.proto D1-D32（5 大类）+ 新增 D33-D40（第 6 大类伴侣纹理） |
| 存储 | `memories.perception_40d` 列，`PerceptionVector40DCodec` 编码为 40 元素 JSON 数组字符串（decode 长度≠40 返回 null） |
| 检索 | 扇区加权余弦 `cosineSimilarity40D`（`VectorReranker`） |
| 立法 | 🔴 P072 业主立法（2026-10-23）：**「除 40D 外其它都是违法」**——全系统禁止任何 40D 以下的子维度切片量纲 |

**数据流**：
```
瑶光（客观医学值）→ 天权 RPC → YaoguangNormalizer 归一化
瑶灵（主观感受值）→ M3 规则引擎
        ↓ 合并
PerceptionV40（40D 感知向量）
        ↓ PerceptionVector40DCodec.encode
memories.perception_40d 落库
        ↓ 检索时
扇区加权余弦相似度（VectorReranker）
```
